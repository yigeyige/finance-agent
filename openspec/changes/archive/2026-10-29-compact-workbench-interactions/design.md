## Context

Vue 2.7.16 / Element UI 2.0.0 已提供带边框表格的 header-dragend；现有 th.el-table__cell 密度选择器与旧版 DOM 不匹配。公共样式、页面 scoped 样式分散控制密度，三个业务表单共用 workbench-dialog。用户确认全部右侧页面适度紧凑，不动菜单，由用户启动和人工验收。

## Goals / Non-Goals

**Goals:** 右侧充分利用宽度；统一边距和卡片层级；持久化列宽；弹窗可移动、缩放、最大化、还原。

**Non-Goals:** 不调整侧栏、业务流程、API、权限；不增加列排序、列显隐、恢复列宽按钮；不扩展确认消息框交互。

## Decisions

- 沿用暖白、橙色和现有字体。公共密度规则限于工作台内容区域；顶栏 64px，外边距 12–16px，列表充分展开，长文本页限制阅读行宽。
- 两个 Vue 指令显式接入各表格和三个弹窗，避免全局 mixin 或改造 Element 组件。几何边界和列宽存储单独封装，可运行无浏览器逻辑测试。
- 表格标识固定于页面和位置，字段 schema 区分动态结果。仅保存字段标识和有效像素宽度；异常 JSON、存储禁用、schema 变化自动降级，不阻断业务；卸载时释放监听。
- Element 原生 tooltip 展示省略文本，表格自身保留横向滚动，动态证据列有合理初始最小宽度。
- 弹窗以 Pointer Events 操作，标题栏移动、右下角调整尺寸；最大化按钮支持键盘，缩放柄支持方向键。内容 flex 滚动，页脚不收缩；关闭重置、缩小视口重新约束、卸载清理事件。

## Risks / Trade-offs

- [旧版 Element 内部列模型] → 限定访问范围并执行编译和行为测试，列 schema 变化后重建恢复状态。
- [窄屏拖动越界或隐藏操作] → 视口边界优先于默认最小尺寸，页脚固定于弹窗内部。
- [视觉结果需人工确认] → 不启动环境，交付人工验收项；静态和编译不作为浏览器拖拽验收。
- [共享样式影响侧栏] → 不编辑侧栏规则，差异检查保护菜单结构与样式。

## Migration Plan

无服务端迁移，无新依赖。回退本任务前端文件即可撤销交互；旧列宽存储使用版本前缀，不影响业务。

## Open Questions

无，用户已确认四项设计取舍。
