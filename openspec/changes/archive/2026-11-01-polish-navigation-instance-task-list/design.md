## Context

工作台使用 Vue 2、Element UI 2 和暖白卡片样式。任务列表由受身份约束的服务端分页提供，目前响应不含名称与业务上下文。数据库实例页使用固定列宽，使宽屏仍可能出现横向滚动。

## Goals / Non-Goals

**Goals:** 精简菜单与页面层级；在任务列表展示可信只读字段；让分页与滚动位于稳定布局内。

**Non-Goals:** 不改变权限、任务数据、数据库连接安全约束或详情页流程。

## Decisions

- 菜单只隐藏知识域入口，保留受权限保护的路由，避免破坏旧深链。
- 列表接口在既有分页结果映射时补齐发起人显示名、场景名称和实例名称；缺失或已删除的关联显示为空，不回退显示内部 UUID，也不返回实例连接信息。
- 业务说明取任务原始说明，在表格中单行截断并保留悬浮全文。
- 表格高度随视口变化并在 Element UI 表体内滚动；窄屏保留横向滚动，宽屏列采用可伸缩最小宽度。
- 服务端返回的页码与页大小用于校正分页组件状态，筛选和切换条数仍重置第一页。

## Risks / Trade-offs

- 关联名称按当前配置读取，历史任务名称可能随配置更名而变化；列表用于识别当前关联，审计标识仍保留在详情。
- 最窄视口下列较多，仍需在表格内横向滚动；不缩小字体来压缩信息。
