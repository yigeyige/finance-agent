## Context

任务详情是受权限保护的只读投影。任务列表已能从用户、场景关联、实例仓储读取展示名称；详情目前只有发起人 ID。创建页使用双列表单，详情使用定义列表。

## Goals / Non-Goals

**Goals:** 在权限检查后补齐展示名称；详情只读字段顺序与创建页一致；标题栏和决策包卡片保持间距。

**Non-Goals:** 不改变任务绑定、编辑、附件或决策包生成逻辑。

## Decisions

- 复用 `TaskListRowService` 已有名称查询并为详情开放只读显示名称投影，避免另一套关联解析逻辑。只有通过详情权限检查后才查询名称。
- 三个展示字段保持独立，原 `initiatorUserId` 留在接口用于既有契约兼容，但页面仅展示名称。场景与实例无关联时返回 null，前端显示“—”。
- 业务说明使用创建页相同的双列字段节奏和现有 `task-form` 样式，文本为只读内容，不增加禁用输入框或提示。

## Risks / Trade-offs

- 旧后端未返回新增字段时前端以“—”降级，避免前端先更新期间详情完全无法读取；字段类型错误仍拒绝。
- 当前关联名称可能随配置名称改变；详情显示当前名称，与任务列表保持一致。

## Migration Plan

先部署后端再部署前端。回滚可恢复两侧代码与契约，无数据库迁移。
