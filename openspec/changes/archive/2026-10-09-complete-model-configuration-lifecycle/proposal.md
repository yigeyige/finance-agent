## Why

模型连接管理已支持创建、编辑与唯一启用，但管理员无法主动停用当前连接。这使系统不能进入明确的“模型维护中、禁止调用”的安全状态，也与既有模型连接管理规格不一致。

## What Changes

- 新增管理员停用指定大模型连接的 REST 接口，保留更新人和更新时间审计。
- 在模型连接配置页面加入确认式停用操作，并在停用后刷新状态。
- 将停用路径补充到 OpenAPI 与前端临时生成边界，并以服务单元测试覆盖无启用连接的安全失败语义。

## Capabilities

### Modified Capabilities

- `model-connection-management`: 明确平台管理员停用连接、运行时不再选择已停用连接及无启用连接时的安全行为。

## Impact

- 模型连接应用服务、REST 控制器及单元测试。
- OpenAPI、前端生成类型边界、模型配置服务与页面。
- 不引入数据库迁移，不删除连接配置，不改变 API Key 存储方式。
