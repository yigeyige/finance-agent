## Context

任务列表已具备受身份范围约束的分页查询、关键词和状态筛选，以及双击只读详情能力。当前页面仅有一个表格面板，筛选表单位于表格内部，难以识别操作入口和数据区边界。

## Goals / Non-Goals

**Goals:**

- 用现有 Element UI 组件重新编排页面层级，使概览、筛选操作和记录表格清晰分离。
- 让查询、重置和新建业务处理操作在同一操作组中可快速使用。
- 保持既有数据请求、分页、详情跳转和身份范围行为。

**Non-Goals:**

- 不新增或修改后端接口、任务数据和权限规则。
- 不修改任务详情页面，也不在列表页提供历史任务编辑能力。

## Decisions

- 使用任务概览卡片展示总数、当前显示数和页码，采用分隔列呈现，呼应业务工作台信息块的视觉层级；不引入图表或新依赖，避免将简单列表变成复杂仪表盘。
- 使用独立的筛选操作卡片承载字段和按钮，表格仅承载业务处理记录；这使查询操作与数据阅读分离，同时保留 Element UI 表单、表格和分页组件。
- 仅在 `TaskList.vue` 添加局部样式，以避免影响其他标准表格页面。

## Risks / Trade-offs

- [窄屏下字段和按钮拥挤] → 通过响应式断点改为纵向布局，按钮允许换行。
- [概览统计在加载过程中短暂显示旧值] → 沿用表格加载状态，概览显示当前已加载结果，不引入额外请求。
