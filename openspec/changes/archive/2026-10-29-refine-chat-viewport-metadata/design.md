## Context

聊天组件有 720px 最大高度和两行输入区。现有建议响应 metadata 已含实际模型、tokens、latencyMillis，但仅对应最后一次建议生成调用；管理员配置列表包含连接信息，不能为操作员展示模型名而开放该列表。

## Goals / Non-Goals

**Goals:** 页标题一致、聊天填满剩余视口、紧凑输入、可信模型与最近调用统计。

**Non-Goals:** 不统计任务全部模型调用或计费，不新增数据库迁移，不改变已有调用流程，不扩大配置列表权限。

## Decisions

- 新增 GET /api/v1/model-runtime：应用服务根据运行模式与已有启用配置读取 mode/modelName，控制器要求 OPERATOR（管理员继承）。响应是专用 DTO，不返回配置 Entity、API 地址或密钥。
- 新接口通过 OpenAPI、JSON Schema 和前端严格解析同步版本；无启用模型返回 LIVE/null，读取失败仅影响元信息，不阻断业务说明。
- 初始模型来自运行摘要，最近调用后使用返回 metadata 显示实际使用模型和 Token/耗时。清空草稿同步清空调用摘要；刷新后不虚构历史累计。
- 聊天测量自身实际顶部位置，以视口高度减去顶部和底部安全边距设置高度；在视口、任务布局变化及缓存激活时更新，并清理观察器和监听。消息正文独立滚动，窄屏保持正常页面滚动。
- 输入区 flex 同排，输入弹性占宽、按钮固定且文案“发送”；顶部元信息 14px，允许自然换行，空闲无等待状态。

## Risks / Trade-offs

- [Token 口径误读] → 显示“最近调用 Token”，不命名为累计/总消耗。
- [配置与最近调用模型不一致] → 标明“当前模型”和“最近调用”两个信息来源，最近调用完整信息通过可访问说明保留模型名。
- [窗口高度变化循环] → 仅尺寸变化时写入，观察器更新经过动画帧合并，卸载清理。
- [后端新接口尚未重启] → 前端安全显示信息不可用，用户重启后验收，不自动重启服务。
