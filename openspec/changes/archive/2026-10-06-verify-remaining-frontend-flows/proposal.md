## Why

前端主流程能创建和审批任务，但在继续回归时发现深链刷新被路由守卫误拦截、返回工作台后丢失当前任务、同路由参数切换不重新加载，并且 Element UI 2.0.0 不支持的标签产生运行时告警。这些问题会让诊断、证据和决策包后续操作在真实页面中不稳定。

## What Changes

- 路由权限判断在首次深链进入时先等待服务端身份加载，再决定是否放行。
- 工作台在应用内进入诊断、证据或决策包页面后保留当前任务上下文，后续页面按明确目标路由返回。
- 任务详情类页面在 `taskId` 变化时重新查询，避免展示上一个任务的缓存数据。
- SSE 断线后使用最新游标显式恢复，页面用非误导的中文状态表达等待新进度。
- 移除对 Element UI 2.0.0 未提供组件的使用，用项目内已有结构和样式表达分隔、空状态和描述信息，并修正输入组件属性类型告警。

## Capabilities

### New Capabilities

- `frontend-workflow-navigation`: 覆盖工作台任务上下文保留、明确返回目标和路由参数变化后的数据重新加载。
- `frontend-component-compatibility`: 覆盖前端对固定 Element UI 2.0.0 基线的组件兼容性要求。

### Modified Capabilities

- `frontend-identity-navigation`: 首次直接进入受保护页面时，路由守卫必须先完成身份加载。
- `frontend-sse-client`: 断线恢复必须显式携带最新游标，并区分可恢复的等待状态与消息解析错误。

## Impact

- 影响前端路由守卫、身份缓存、工作台容器、SSE 客户端及诊断/证据/决策包相关 Vue 页面。
- 不改变后端 API 契约、数据库或依赖版本。
- 验证包括真实本地 API 操作、浏览器深链/返回/参数切换回归、TypeScript 检查和 Vite 构建。
