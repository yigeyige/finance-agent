## Context

数据探索左侧使用 `el-tree`，当前节点标题优先取表注释，选表时又把标题写回元数据注释。目录树处于不限制高度的侧栏中，展开大量表会撑高页面。工作台已有独立滚动列表和暖白卡片样式。

## Goals / Non-Goals

**Goals:** 表节点只显示表名，注释继续参与搜索及元数据；宽屏把长目录的滚动限制在左侧树区域，窄屏保持可访问。

**Non-Goals:** 不改字段查询、SQL 执行、后端目录或数据库结构。

## Decisions

- 树节点 `label` 固定为表名，注释独立放在节点字段，选表时保留真实注释；搜索逻辑仍匹配两者。
- 左侧目录改为纵向 flex，树放入 `min-height: 0` 的内部滚动容器。桌面主布局按视口高度约束；右侧内容保留独立可滚动访问。窄屏布局自然堆叠，目录树限制最大高度并自身滚动。
- 沿用现有 Element UI 树、查询组件和工作台配色，不新增视觉组件。

## Risks / Trade-offs

- 桌面窗口较矮时固定高度可能压缩目录 → 设合理最小高度，页面仍可自然滚动。
- 表名较长时单行截断 → 通过节点 `title` 展示完整表名，不改变实际文本。
