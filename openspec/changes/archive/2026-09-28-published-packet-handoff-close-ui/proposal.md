# 发布查看、交接和关闭

## Why

发布后的决策包需要由操作员和查看员以同一份不可变修订为依据查看，并能记录外部责任与流程交接。调查关闭必须保留发布内容和交接历史，且不能被误解为整改已完成。

## What Changes

- 增加面向 OPERATOR/VIEWER 的最新已发布修订查询接口和页面，展示核查时点、版本、覆盖摘要与限制。
- 增加 OPERATOR 交接接口，登记责任引用、外部流程引用和下游状态，并推进任务到 HANDED_OFF。
- 增加 OPERATOR 关闭接口，要求已有责任引用，推进任务到 CLOSED，明确整改完成状态仍为未确认。
- 复用现有任务状态机、审计链和权限拦截器，不修改已发布修订内容。

## Scope

仅覆盖现有工作台的发布查看、交接和关闭，不引入外部系统写入或整改执行能力。
