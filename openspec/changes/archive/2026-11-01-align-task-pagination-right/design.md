## Context

任务列表使用 Element UI 2 分页组件，当前布局 `total, sizes, ->, prev, pager, next` 将总数与每页条数留在左侧，翻页按钮放到右侧。截图中空列表进一步暴露了左下角控件位置问题。

## Goals / Non-Goals

**Goals:** 分页所有控件在表格右下角集中排列。

**Non-Goals:** 不改变分页请求、筛选逻辑、控件数量和服务端数据契约。

## Decisions

- 使用 Element UI 既有的 `->` 布局分隔符，将其移到所有分页控件之前；该组件会把分隔符之后的控件放进右侧容器。继续复用既有组件和样式。
- 小屏遵循已有分页换行规则，避免隐藏控件。

## Risks / Trade-offs

- 极窄视口下分页控件仍可能换行；保持可操作性优先，浏览器实际效果由操作人手动验收。
