## Context

任务详情接口目前返回决策包和场景名称，缺少可直接判断提示词的稳定 ID。场景列表接口会返回全部提示词正文，不适合作为入口状态查询。现有生成服务以非空白 `processArtifactPrompt` 为必要条件。

## Goals / Non-Goals

**Goals:** 通过任务关联 ID 判断当前有效场景的提示词配置，只向前端返回布尔值；决策包详情先展示，按钮状态异步补充；保持任务查看权限。

**Non-Goals:** 不改变流程文件生成校验、弹窗下载、数据库结构或场景提示词配置。

## Decisions

- 增加 `GET /api/v1/tasks/{taskId}/process-artifact-availability`，返回 `{ "available": boolean }`。应用服务先校验任务可见性，再查询决策包、任务场景关联与有效场景提示词。缺失任一条件返回 false；无权任务继续按详情接口返回不存在错误。
- 前端在任务详情成功且存在决策包时启动独立请求，不等待结果渲染主体。入口默认隐藏，仅在查询明确返回 true 时出现。使用任务 ID 对比丢弃过期响应。
- 查询失败保留错误状态，决策包正常展示；入口不在未知状态下显示。页面可重载后重试。

## Risks / Trade-offs

- 多一次只读请求 → 异步执行，不阻塞决策包主体。
- 场景配置在页面打开后被修改 → 页面重新加载后更新入口；生成服务仍独立校验当前配置。
