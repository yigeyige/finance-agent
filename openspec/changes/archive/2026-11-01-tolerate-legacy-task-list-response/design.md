## Context

新列表接口已扩展展示字段，但本地启动的后端可能仍提供旧响应。前端解析器把新字段当作必填，缺失时整页报错。

## Goals / Non-Goals

**Goals:** 让旧响应继续展示基础任务和分页，新字段暂以占位符显示；保留完整新响应和错误类型的校验。

**Non-Goals:** 不修改后端接口、不用发起人 ID 冒充名称、不读取数据库连接详情。

## Decisions

- 仅在 `description`、`initiatorName` 字段完全缺失时填入“—”；字段存在但类型错误时继续拒绝。
- 可选关联名称仍使用现有可空解析，旧响应缺失时为 `null`，页面统一显示“—”。
- 不放宽额外字段白名单，避免凭据被列表解析接受。

## Risks / Trade-offs

- 旧后端仍无法提供新增真实值；用户重新启动并使用更新后的后端后，列表才显示完整字段。
