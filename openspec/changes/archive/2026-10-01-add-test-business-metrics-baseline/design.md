## Context

P1 的固定参考样本已经定义当前、未来、未知和无匹配事实，试点预检已输出覆盖、未知和人工确认计数。P1-008 需要量测，但运行时指标必须由项目负责人从 local 执行产物采集，不能用静态值替代。

## Goals / Non-Goals

**Goals:**

- 从固定样本和预检结果计算样本侧准确率、召回率、分类准确率、未知率、覆盖及人工确认数。
- 为小、中、大三档运行时采集提供无预填数值的原始数据模板。

**Non-Goals:**

- 不启动环境、不执行压测、不填写延迟、并发、数据库规模、Token、成本或签署阈值。
- 不以固定测试样本代表真实业务或生产容量。

## Decisions

### 1. 样本指标与运行时指标分离

样本指标通过只读聚合服务确定性计算；运行时指标使用 `PENDING_USER` 数据状态。这样避免把编译时或单元测试耗时误当作 API 性能。替代方案是生成默认阈值；未采用，因为违反“不预填目标”。

### 2. 三档规模仅定义采集计划

小、中、大档只定义样本批次数和待采集字段，不声称已执行。实际档位值和签署由用户补充。替代方案是虚构压测数据；未采用，因为无法作为 P1 证据。

## Risks / Trade-offs

- [无运行时数据无法形成容量结论] → 显式保留待采集状态和容量调整待办。
- [样本指标被误用为生产指标] → 所有结果携带测试样本版本和 local/test 边界。

## Migration Plan

1. 增加测试样本指标聚合和单元测试。
2. 交付三档原始数据模板、待签署阈值和容量调整清单。
3. 用户采集 local 运行时数据后补充 P1-008，不自动归档。
