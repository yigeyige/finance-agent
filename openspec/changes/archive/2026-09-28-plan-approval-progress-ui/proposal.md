## Why

工作台已能创建任务和确认范围，但还不能展示计划、审批绑定或公开实时进度，用户无法在执行前理解读取范围和调用上限。此变更接入已有步骤提议、审批和 SSE 接口，形成可人工验收的执行前门禁。

## What Changes

- 展示一个推荐步骤和最多两个备选步骤。
- 展示来源、范围、字段策略、查询模板、调用上限和有效期等审批绑定，并支持批准/拒绝。
- 通过游标 SSE 展示脱敏公开事件，过滤跨任务事件并处理断线状态。

## Capabilities

### New Capabilities
- `plan-approval-progress-ui`: 计划、审批卡和公开实时进度工作台。

### Modified Capabilities

## Impact

- 影响前端领域类型、执行 API 服务、工作台页面和 SSE local/test 身份传递。
- 不新增依赖，不展示推理链或原始模型响应。
