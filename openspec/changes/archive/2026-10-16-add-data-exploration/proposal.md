## Why

平台管理员目前只能在业务处理模型调用中间接使用 EMS 只读数据，无法在工作台中快速核对允许范围内的表结构或执行受控查询。新增独立的数据探索入口，可在不扩大写库权限与不暴露连接凭据的前提下提升运维排查效率。

## What Changes

- 新增平台管理员专用的数据探索菜单、路由和 SQL 工作台页面。
- 新增受控表目录和字段结构读取接口，仅暴露允许 EMS 业务库的元数据。
- 新增直接查询接口，复用已启用 EMS 连接、既有只读 SQL Guard、超时、行数和结果投影边界。
- 页面支持数据源状态、表搜索、单条 SQL 输入、20/50/100 行限制、查询结果和表结构展示。
- 首版明确不提供写操作、导出、持久化历史、收藏或第三方 SQL 编辑器依赖。

## Capabilities

### New Capabilities

- `data-exploration`: 平台管理员通过工作台安全浏览允许的 EMS 元数据并执行受控只读查询。

### Modified Capabilities

- 无。

## Impact

- 前端：侧栏菜单、路由、数据探索页面、API 服务及生成契约。
- 后端：数据探索 Web/API、应用服务、受控元数据读取和只读查询编排。
- 安全：复用 `PLATFORM_ADMIN`、已启用 EMS 连接和 SQL Guard；不新增数据库凭据或外部依赖。
