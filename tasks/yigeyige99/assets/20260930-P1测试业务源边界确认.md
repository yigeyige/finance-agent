# P1 测试业务源边界确认

## 确认结论

P1 只使用本仓库中固定、离线的测试业务源，以及虚构或已脱敏样本；不接入生产系统、真实业务数据、真实人员、金额、单据、凭证或生产配置。

本确认仅授权 `DEV-P1-002` 冻结测试 SourceCatalog 和字段策略，不构成真实源、生产统一认证、真实字段权限或生产发布的批准。

## 适用范围

| 项目 | 约束 |
|---|---|
| 运行环境 | 本地或测试环境；不允许 prod profile 使用测试身份或测试源作为生产事实 |
| 唯一测试源 | `SyntheticConfigSourceAdapter`，完全离线、固定 seed |
| 目录版本 | `source-catalog-v1` |
| 数据版本 | `synthetic-config-v1` |
| 查询模板 | `config.employee.references.v1` |
| 允许参数 | `page`、`size`；均为正整数，`size` 不得超过 `100` |
| 测试身份 | `EMP-SYN-*` 仅为虚构标识，不映射真实人员 |
| 故障策略 | 目录、模板、参数或字段权限不符合约定时拒绝；不得回退连接真实源 |

## 生产边界

真实源对象、物理字段、权限矩阵、凭证、责任人、认证协议与生产验收必须在 P2 另行确认并留存证据。P1 的测试目录、场景或验证结果不得被用作生产接入凭据。
