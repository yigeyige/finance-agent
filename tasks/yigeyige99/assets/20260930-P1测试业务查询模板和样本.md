# P1 测试业务查询模板和样本

## 查询模板

```text
templateCode = config.employee.references.v1
catalogVersion = source-catalog-v1
parameters = { page: 正整数, size: 1..100 }
```

不接受 SQL、URL、写意图、未知参数、非正页号、`size > 100` 或非登记目录版本。

## 有效样本

| 场景 | 输入 | 预期结果 |
|---|---|---|
| `BASELINE` | `page=1`、`size=2`、固定 seed | 返回 `EMP-SYN-001` 的一个 `CURRENT` 引用和一个 `FUTURE` 引用 |
| `COMPLETE_NO_MATCH` | 合法模板和参数 | 返回空记录集，表示测试范围内无匹配，不外推全范围结论 |
| `PARTIAL_NO_MATCH` | 合法模板和参数 | 返回 `UNKNOWN`，不产生确认事实 |
| `CROSS_SOURCE_CONFLICT` | 合法模板和参数 | 返回 `CONFLICT`，不由模型或候选顺序裁决 |
| `FUTURE_REFERENCE` | 合法模板和参数 | 返回 `FUTURE`，不归类为当前事实 |
| `UNKNOWN_GAP` | 合法模板和参数 | 返回 `UNKNOWN`，需要人工或后续权威来源处理 |
| `NEW_REFERENCE` | 合法模板和参数 | 返回 `NEW`，可用于发布前重查失效测试 |

## 无效样本

| 输入或场景 | 预期结果 |
|---|---|
| `templateCode=select * from employee` | 拒绝，不执行外部操作 |
| 参数包含 `sql`、URL 或写意图 | 拒绝，不执行外部操作 |
| `page=0`、非数字页号或 `size=101` | 拒绝参数 |
| 目录版本不是 `source-catalog-v1` | 拒绝目录版本 |
| `PAGINATION_FAILURE` 的第二页 | 返回稳定分页失败；不得改连真实源或伪造空成功页 |
| 未登记字段进入读取、留存或送模 | 拒绝字段，且不写入测试以外的存储或模型输入 |
