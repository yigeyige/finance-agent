# P1 测试认证适配器操作说明

## 适用范围

本说明只适用于 `local` 和 `test` profile 的测试业务源验证。认证适配器复用 `IdentityResolver`、`IdentityContextFilter` 和已登记的合成身份；它不是 SSO、JWT 或生产统一认证实现。

## 启用与身份选择

1. 在 local/test 环境显式开启 `finance-agent.identity.seed-enabled=true`，由现有种子创建测试用户与角色。
2. 业务 API 请求使用 `X-Test-Identity` 选择下列白名单身份：

| 请求头值 | 测试用户 | 角色 | 允许范围 |
|---|---|---|---|
| `operator` | `local-operator` | `OPERATOR` | 任务操作与测试调查流程 |
| `viewer` | `local-viewer` | `VIEWER` | 已发布内容和允许的只读视图 |
| `platform-admin` | `local-admin` | `PLATFORM_ADMIN` | 测试配置管理边界，不自动获得源范围权限 |

3. 请求结束后 `IdentityContextFilter` 会清理线程上下文；业务写操作从当前身份上下文取操作者，不信任请求体自报用户。

## 失败关闭与生产隔离

- 未携带、拼写错误或不在白名单中的 `X-Test-Identity` 不建立当前身份，受保护操作必须拒绝。
- 角色绑定已撤销时，不建立当前身份；不会构造无角色身份。
- `prod` profile 不解析测试身份，也不注册合成身份种子。不得传递测试身份头、测试用户标识、测试数据或任何本地配置到生产环境。
- 真实 issuer、claims、人员编号映射、Token/JWT 和 break-glass 流程属于 P2，不能使用本说明或测试结果替代其批准与验收。
