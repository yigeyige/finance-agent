# P1 测试业务 SourceCatalog

## 目录元数据

| 项目 | 值 |
|---|---|
| 目录版本 | `source-catalog-v1` |
| 数据版本 | `synthetic-config-v1` |
| 来源标识 | `SyntheticConfigSourceAdapter` |
| 权威级别 | 仅在 P1 测试范围内作为唯一登记的受控样本源；不对生产事实或真实业务对象声明权威性 |
| 数据形态 | 固定、离线、虚构记录；相同 seed、模板和参数返回相同结果 |
| 可访问环境 | `local`、`test` |
| 禁止环境 | `prod` |

## 对象与查询

| 对象 | 逻辑用途 | 查询模板 | 参数 | 分页与排序 | 水位/版本 | 生效语义 | 错误语义 |
|---|---|---|---|---|---|---|---|
| 人员关联测试记录 | 验证人员与配置引用的当前、未来、未知及冲突分类 | `config.employee.references.v1` | `page`、`size` | 页号从 `1` 开始，`size` 为 `1` 至 `100`；结果顺序仅由固定场景和 seed 决定，不承诺真实源排序 | 返回 `synthetic-config-v1` 和结果摘要；不提供真实源水位 | `CURRENT`、`FUTURE`、`UNKNOWN`、`CONFLICT`、`NEW` 仅为测试分类 | 模板、参数、目录版本未登记或分页失败时拒绝；不得返回伪造成功页或连接真实源 |

## 目录使用约束

1. 只允许本文件登记的对象、模板、参数与字段矩阵。
2. 不允许 SQL、任意 URL、写操作、真实凭证或生产连接串。
3. `UNKNOWN` 和 `CONFLICT` 不能作为确认事实；需要人工复核或未来权威来源处理。
4. 任何未来新增对象、字段或真实源都必须建立独立 P2 变更并重新取得授权。
