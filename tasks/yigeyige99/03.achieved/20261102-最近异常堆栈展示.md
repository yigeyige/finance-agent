## 需求

### ID&标题

最近一次业务与模型异常堆栈展示

### 描述

左侧菜单新增异常堆栈页面，展示本服务最近一次未预期业务接口异常或最终失败的任意模型交互异常的堆栈。服务单实例运行，仅在内存保存一条，页面打开时读取一次，不自动刷新。

## 背景

统一异常处理器目前只记录摘要，模型交互失败可能由单独处理器或客户端转换。管理员缺少快速查看最近失败代码位置的入口。

## 目标

- [x] 内存只保留最近一次符合范围的异常快照，重启后自然清空。
- [x] 平台管理员可通过左侧菜单与只读接口查看快照，其他身份不可访问。
- [x] 显示发生时间、异常类型与堆栈帧；过滤敏感信息，不展示原始业务数据、提示词或密钥。
- [x] 页面仅在进入时读取一次，空状态和读取失败可理解。

## 验收标准

- 未预期业务接口异常和任何最终失败的模型调用异常覆盖最近记录；普通业务拒绝及已恢复的模型失败不覆盖。
- 同时只有一条不可变快照，不保留 Throwable；无需数据库、定时轮询或推送。
- 平台管理员以外无法读取接口或进入页面；页面不显示敏感原文。
- 后端相关测试、前端测试、类型检查、构建与 OpenSpec 严格校验通过；运行环境由操作人手动验收。
