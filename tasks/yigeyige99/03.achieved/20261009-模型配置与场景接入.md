## 需求

### ID&标题

- 大模型配置管理与业务场景 Skill 接入模型分析

### 描述

- 业务场景 Skill 要进入对应场景的大模型分析逻辑，作为受控的场景上下文。
- 大模型配置不再从 YAML 或环境变量读取；管理员通过左侧“大模型配置”页面维护 API 地址、API Key、模型名称等信息。
- 模型调用从数据库读取当前启用的大模型配置，不向前端或日志返回 API Key。

## 背景

- 当前 DeepSeek 适配器直接依赖 Spring 配置属性，管理员无法在工作台维护模型连接信息。
- 当前业务场景 Skill 只在目录中维护，尚未成为业务处理初稿生成和聊天修订的场景依据。

## 目标

- [x] 管理员可在工作台维护一套当前启用的大模型连接配置。
- [x] API Key 仅允许写入和更换，查询接口不返回明文，日志和模型调用元数据不泄露密钥。
- [x] 业务处理模型调用能按任务匹配场景 Skill，并将其业务内容作为受控上下文。
- [x] 当没有启用配置或场景不匹配时，系统以明确、可理解的方式失败或降级。

## 验收标准

- 左侧菜单提供“大模型配置”，管理员可新增、编辑、启停和切换当前启用配置。
- 配置列表和详情不返回 API Key；编辑时仅可选择保留或更新密钥。
- 模型适配器不再读取 API URL、API Key、模型名等 YAML 或环境变量作为运行时模型配置来源。
- 生成业务处理初稿和聊天修订时，匹配的业务场景 Skill 会进入受限模型输入，模型调用元数据反映所用配置但不包含密钥。
- 前后端相关测试、类型检查、构建、迁移校验和 OpenSpec 校验通过。
