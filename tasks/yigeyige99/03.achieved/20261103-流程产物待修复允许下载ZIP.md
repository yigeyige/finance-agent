## 需求

### ID&标题

- 流程产物待修复时允许下载 ZIP

### 描述

- 流程产物即使状态为 `NEEDS_REPAIR`，只要存在产物且包含模型文件，就允许用户下载 ZIP，供人工继续处理。

## 背景

当前前端仅在 `IMPORT_CANDIDATE` 状态启用 ZIP 下载，后端也拒绝 `NEEDS_REPAIR` 批次。业务上模型生成的流程通常需要人工补充，待修复产物也需要整体下载。

## 目标

- [x] 前端对存在流程产物模型文件的批次启用 ZIP 下载按钮。
- [x] 后端允许待修复批次打包下载，同时保留模型文件必选和文件类型白名单校验。
- [x] 补充并通过前后端相关自动化验证。

## 验收标准

- `NEEDS_REPAIR` 批次可以下载包含模型文件的 ZIP。
- 不存在模型文件、包含非法文件类型或批次不存在时仍然失败。
- `IMPORT_CANDIDATE` 原有下载行为不回归。
