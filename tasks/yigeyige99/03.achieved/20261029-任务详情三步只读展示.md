## 需求

### ID&标题

自定义需求，ID 为空。任务详情三步只读展示。

### 描述

从任务列表双击打开任务后，任务界面改为与新建业务处理（业务说明/模型协作/决策包）一致的三步布局；隐藏模型聊天框与全部业务操作按钮，仅保留步骤切换查看。

## 背景

当前双击任务行进入 `/tasks/:taskId` 的 `TaskDetail`，以扁平卡片只读展示业务说明、检查结论、关联证据与决策包。用户希望该详情页与新建业务处理工作台的三步展示保持一致，但为只读：不显示右侧模型聊天框，不显示保存/开始分析/生成决策包等操作按钮，只允许点击顶部步骤切换查看。

## 目标

- [x] 任务详情使用与新建业务处理一致的三步条（业务说明、模型协作、决策包），步骤可点击切换
- [x] 隐藏右侧模型聊天框
- [x] 隐藏全部业务操作按钮，仅保留页面导航（返回任务列表）

## 验收标准

- [x] 双击任务列表行进入详情后，顶部三步条与新建业务处理一致，点击各步骤可切换内容

- [x] 三步内容中不出现保存任务、开始模型分析、重新开始模型分析、生成决策包、查看决策包、返回模型协作等操作按钮
- [x] 结论、证据或决策包缺失时展示对应空状态文案
