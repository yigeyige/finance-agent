## 需求

### ID&标题

- 简化业务操作流程并隐藏 JSON 技术输入

### 描述

- 当前前端操作步骤复杂，业务人员不清楚流程，也不知道如何填写 JSON、UUID、摘要和版本等技术字段，需要改为可理解的业务向导。

## 背景

- 任务发起、范围确认、步骤审批、决策包组装和发布页面直接暴露了接口级技术字段。
- 这些字段可以根据业务表单、当前任务和已有证据自动生成，不应要求业务人员理解内部数据结构。

## 目标

- [x] 将任务发起和审批流程改为业务语言与分步引导。
- [x] 自动生成范围、审批、决策包和发布所需的技术数据，不再要求手工填写 JSON。
- [x] 将原始 JSON 降级为只读技术明细，默认不干扰业务主流程。
- [x] 完成类型检查、构建和核心前端流程验证。

## 验收标准

- 主流程不出现需要业务人员填写的 JSON、UUID、哈希或内部版本输入框。
- 每个阶段说明当前目标、需要确认的业务信息和下一步操作。
- 决策包可从任务证据自动形成，发布重查数据由系统自动准备。
- `npm run typecheck`、`npm run build` 和 OpenSpec 严格校验通过。

## 执行记录

- 2026-10-06：从用户反馈接入，开始简化业务操作流程。
- 2026-10-06：将任务发起重构为“说明问题、确认对象、设置范围、批准方案”四步业务向导，范围和审批技术绑定由系统自动生成。
- 2026-10-06：决策包改为读取现有证据自动组装，发布前自动准备基线和当前快照；原始 JSON 仅在默认收起的技术明细中只读展示。
- 2026-10-06：完成窄屏响应式优化，并通过前端类型检查、生产构建、OpenSpec 严格校验和浏览器核心流程验证。
