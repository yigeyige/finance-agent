## 需求

### ID&标题

初稿模型输出上限与超时调整

### 描述

生产将使用内网模型，模型预算不敏感。将初稿调用的输出上限和超时时间调大，以适配较大用户输入和复杂流程：

- `GUIDANCE_MAX_TOKENS`：`65,536` → `131,072`（模型官方最大输出 384K，后续可继续提到 256K）；
- `TIMEOUT`：`240s` → `600s`（与前端 `MODEL_TIMEOUT=600s` 对齐）。

## 背景

`deepseek-flash` 初稿调用曾因 16K 输出预算被推理内容占满导致 JSON 截断；已先提到 65,536。生产改用内网模型后预算不敏感，用户输入可能更多，需要更大的输出与超时余量。

## 目标

- [x] 所有模型调用统一 `DEFAULT_MAX_TOKENS=131072`（选表/规划/初稿/决策包/产物）。
- [x] 模型调用 `TIMEOUT` 调整为 `600s`。
- [x] `ModelInputBudget` 未知模型默认输入上限提高到 `131072` 字节（128K）。
- [x] 重新打包重启，确认后端启动正常。

## 验收标准

- 初稿调用使用 `max_tokens=131072`。
- 模型调用超时为 600s，与前端一致。
- 后端测试/打包通过，重启后端口 8080 正常。
