## 需求

### ID&标题

新增首页并调整登录默认路由

### 描述

- 新增 `/home` 首页，登录后默认进入；`/` 重定向到 `/home`；业务处理迁移到 `/handling`。
- 首页包含：品牌 hero（文案采用 V2：「财务智能运维Agent / 从业务问题到处置方案，一次走完完整闭环 / 自动初筛 · 模型协作 · 决策可追溯」）、业务处理快捷卡、三步使用指南。
- 首页隐藏顶栏大标题，保留右上角用户菜单。
- 本任务不包含 token 用量卡片与后端改造（作为第二个任务）。

## 背景

当前 `/` 直接是业务处理页，登录后也落在业务处理页，缺少介绍与使用引导入口。设计讨论已确认：首页独立为 `/home`，业务处理迁到 `/handling`，所有原根路径跳转同步调整，旧链接 `/` 统一重定向到首页。

## 目标

- [x] 新增 `HomePage.vue`：品牌 hero + 业务处理快捷卡 + 三步指南，视觉延续暖白/淡橙体系
- [x] 路由：`/home` 首页、`/handling` 业务处理、`/` 重定向 `/home`，守卫补身份校验
- [x] 左侧菜单新增“首页”，业务处理指向 `/handling`；首页隐藏顶栏 h1
- [x] 登录成功默认跳 `/home`，保留 `redirect` 参数优先
- [x] 原根路径跳转（菜单、任务列表、业务场景、证据/决策包/诊断返回）统一改到 `/handling`
- [x] 前端类型检查与生产构建通过

## 验收标准

- 登录后进入 `/home`，页面展示 hero、业务处理快捷卡、三步指南；点击快捷卡进入 `/handling` 并重置草稿。
- 直接访问 `/` 会重定向到 `/home`；左侧菜单“首页”“业务处理”高亮与跳转正确。
- 首页无顶栏 h1，其他页面顶栏标题保持不变。
- 未登录访问 `/home`、`/handling` 被守卫带到登录页。
- `npm run typecheck`、`npm run build` 通过。
