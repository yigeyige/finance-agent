## 需求

### ID&标题

任务详情信息与布局优化

### 描述

从任务列表进入任务详情后，业务说明页签显示发起人名称、业务场景和数据库实例，并调整为接近创建模式的布局；决策包页签的流程产物按钮与下方卡片保持间距。

## 背景

当前详情接口仅返回发起人 ID，未返回任务关联的场景和实例名称。业务说明使用定义列表布局，与创建页不一致；决策包标题栏缺少下边距。

## 目标

- [x] 任务详情安全地返回并展示发起人名称、业务场景和数据库实例名称。
- [x] 业务说明页签使用与创建模式接近的只读双列布局。
- [x] 决策包页签流程产物按钮与卡片保持间距。

## 验收标准

- 有关联时显示名称，无关联时显示“—”，不把内部 ID 当作名称。
- 宽屏业务场景和数据库实例同排，窄屏单列；业务标题和说明占整行。
- 流程产物按钮出现时，下方卡片不与标题栏触碰。
- 静态检查、前端构建与相关后端测试通过；运行环境由用户启动和手动验证。
