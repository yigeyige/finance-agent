## 需求

### ID&标题

- 修复 EMS 数据库连接缺失主密钥提示

### 描述

- 修复保存 EMS 数据库连接时，缺少 `FINANCE_AGENT_MODEL_SECRET_KEY` 被错误返回为“当前业务状态已变化”的问题。

## 背景

- 本地 `.env` 未配置模型密钥加密主密钥，保存数据库密码时 AES-GCM 加密安全失败。
- 该场景必须拒绝明文保存，但应返回可操作且不泄露敏感信息的配置错误。

## 目标

- [x] 将缺少加密主密钥映射为明确、安全的配置不可用错误，不再误报状态冲突。
- [x] 为本地运行环境生成不提交 Git 的独立主密钥并重启服务。
- [x] 补充密钥缺失与 API 错误映射测试。

## 验收标准

- 未配置或长度不足的主密钥时，保存请求得到明确的安全错误而不是 `STATE_CONFLICT`，且不返回密码、连接串或底层异常。
- 配置有效主密钥后，管理员可保存 EMS 数据库配置。
- 后端相关测试、编译通过；本地健康检查成功。

## 执行记录

- 2026-10-11：根据用户提供的 traceId 定位到本地加密主密钥缺失；开始修复错误映射与本地安全配置。
- 2026-10-11：增加 `CONFIGURATION_UNAVAILABLE` 安全错误码和密钥缺失回归测试；已写入未纳入版本控制的本地随机主密钥，重启后健康检查返回 200。
