## 需求

### ID&标题

补充后端中文注释

### 描述

为 `backend/` 内的后端代码补充中文注释，并为各方法添加简要中文说明。

## 背景

现有后端代码已具备基础工程、诊断和对象存储能力，但源码中的中文说明不完整，影响业务语义、配置约束和安全边界的快速理解。

## 目标

- [x] 为生产源码中的类、接口、枚举、记录及嵌套类型补充简要中文注释。
- [x] 为生产源码中的构造器和方法补充简要中文注释。
- [x] 保持运行逻辑、接口契约和配置行为不变。
- [x] 完成后端编译与现有测试验证。

## 验收标准

- `backend/src/main/java` 中的业务 Java 源文件均具备类型级中文注释。
- 生产源码中声明的构造器和方法均具备与职责一致的简要中文注释；纯访问器说明其读取或设置的配置含义。
- 不修改方法签名、控制流、配置键或运行时行为。
- `mvn test` 在 `backend/` 目录执行通过。
