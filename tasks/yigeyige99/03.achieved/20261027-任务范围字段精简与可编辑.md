## 需求

### ID&标题

任务范围字段精简与第二步可编辑。

### 描述

1. 任务第二步去掉处理系统、已知情况、信息来源、开始/结束日期、处理内容；只保留处理对象、业务说明、业务场景 Skill、数据库实例（均可编辑）。
2. 后端存在同样字段时一并去掉（草稿、调查范围、任务前提）。
3. 新增任务更新接口，支持在第二步修改业务说明、业务场景 Skill 与数据库实例。

## 背景

- Change 1 已完成任务-数据库实例打通；本 change 收敛第二步字段并支持编辑。
- 草稿/范围/前提仍携带 systemCode、statement、sourceDescription、日期、处理内容、dataUse 等冗余字段。
- 任务与业务场景 Skill 关联当前为不可变设计，需增加可更新能力。

## 目标

- [x] 业务处理草稿去掉 systemCode/statement/sourceDescription/startDate/endDate/investigationAreas/dataUse，仅保留处理对象与方案/结论/证据。
- [x] 调查范围 ScopeRevision 去掉 systemCode/日期范围/处理内容，generatePlan/ModelPlanContext/TaskDetail 同步。
- [x] 任务前提 TaskPremise 只保留处理对象。
- [x] 新增任务更新接口：业务说明、业务场景 Skill、数据库实例可修改并持久化。
- [x] 前端第二步仅展示处理对象、业务说明、业务场景 Skill、数据库实例，且可编辑。
- [x] GUIDE_HANDLING 提示词模板与相关 spec 同步。

## 验收标准

- [x] 后端编译、相关测试、前端类型检查与构建通过。
