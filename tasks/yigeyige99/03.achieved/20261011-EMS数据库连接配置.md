## 需求

### ID&标题

- EMS 数据库连接配置与业务处理模型分析

### 描述

- 在“大模型配置”下增加 EMS 数据库连接配置，供业务处理模型在分析时通过 Agent 受控查询 EMS MySQL 8 数据。
- 连接密码必须加密保存；模型不接触连接凭据。
- 查询只接受单条 `SELECT`；必须在代码中强制拒绝 `UPDATE`、`DELETE`、`TRUNCATE`、`DROP` 等一切写入、DDL、批处理与危险语法。

## 背景

- 已建立 EMS 业务知识域，业务处理模型需要在受控边界内核实审批、角色、会计组、付款权限等运行配置。
- 已核实的数据源为 MySQL 8；Spring Boot 4.0.4 管理的 MySQL Connector/J 版本为 9.6.0。
- 运行环境由用户启动并手工验证；本任务只完成静态检查、编译与自动化测试。

## 目标

- [x] 平台管理员可新增、修改、启停及测试一条 EMS MySQL 连接配置，且密码不以明文保存或返回。
- [x] 为业务处理模型提供受控只读查询工具，并将结果作为非权威辅助上下文传入模型分析。
- [x] 通过统一 SQL 守卫强制只接受单条 `SELECT`，拒绝多语句、注释、DML、DDL、文件读写与非 EMS 业务库访问。
- [x] 在“大模型配置”下增加 EMS 数据库配置菜单和配置页面。
- [x] 补齐后端自动化测试、编译、前端类型检查和生产构建。

## 验收标准

- 管理员可维护并测试 MySQL 8 连接；接口与页面均不回显密码或密文，非管理员不能访问。
- 启用连接后，业务处理模型能通过后端工具获得最多受限行数的只读查询结果；查询异常不会泄露连接、SQL 或数据库错误详情，也不会中断既有模型分析。
- 非 `SELECT`、多语句、注释、`INTO OUTFILE`、系统库或被排除库访问均被代码拒绝，且有定向单元测试。
- 后端定向测试与编译、前端类型检查和生产构建通过。
