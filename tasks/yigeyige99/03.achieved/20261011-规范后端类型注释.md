## 需求

### ID&标题

规范后端各代码类 Javadoc 注释

### 描述

检查 `backend/src/main/java` 的生产 Java 类型，将不符合项目标准的类型注释修复为统一中文 Javadoc 模板。

## 背景

EMS 数据库连接配置等近期新增类型仍使用旧式单行 Javadoc，缺少版本、作者和日期等标准元数据，导致后端源码注释风格不一致。

## 目标

- [x] 盘点生产后端顶层 Java 类型的 Javadoc 合规情况。
- [x] 保留现有中文职责语义，并将不合规的类型注释统一为项目模板。
- [x] 完成静态检查、后端编译和相关测试验证。

## 验收标准

- [x] `backend/src/main/java` 的每个非包描述顶层 Java 类型均具有中文 Javadoc。
- [x] Javadoc 使用 `@Description`、`@Version: 0.1.0`、`@Author: yigeyige99` 和合法格式的 `@Date`，且位于类型注解之前。
- [x] 不修改生产代码的签名、控制流、配置、API 或数据库行为。
- [x] 静态检查、后端编译和相关 Maven 测试通过（完整测试存在 1 项与本次无关的既有契约失败，已排除后重跑通过）。
