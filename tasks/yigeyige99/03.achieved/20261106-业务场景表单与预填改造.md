## 需求

### ID&标题

业务场景全页表单与 AI 预填弹窗（前端）

### 描述

业务场景新建/编辑改为内容区全页表单（侧栏可见），标题右侧「AI 预填」在「返回」左侧；AI 预填弹窗含业务描述、启用数据库实例下拉与三个生成按钮（调查/决策包/流程文件），按字段只读预览后单独应用；调查按钮同时回填场景名称。

## 背景

原新建/编辑使用 1000px 弹窗，字段长文本编辑空间有限；场景维护者需要结合真实表名生成提示词。后端预填接口已完成（第一个任务）。

## 目标

- [x] 列表与全页表单在内容区切换，返回时未保存修改二次确认
- [x] 表单字段与附件搬入全页，调查提示词上限对齐 8000
- [x] AI 预填弹窗：文本 + 实例下拉 + 三个生成按钮，按字段预览与应用
- [x] 调查按钮同时回填名称；决策包/流程文件缺前置提示词时前端阻断
- [x] 新增前端 API/类型，typecheck、测试、构建通过

## 验收标准

- 新增/编辑不再使用弹窗，表单占满内容区且侧栏可见；返回有未保存修改时需确认。
- 三个生成按钮分别预览对应字段，应用只覆盖对应字段；调查按钮同时覆盖名称。
- 未选实例也可生成；选择实例后展示使用/排除表数量与无表提示。
- `npm run typecheck`、`npm test`、`npm run build` 通过。
