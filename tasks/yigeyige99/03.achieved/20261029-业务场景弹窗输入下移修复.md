## 需求

### ID&标题

自定义需求，ID 为空。业务场景弹窗输入下移修复。

### 描述

修复业务场景 Skill 新建/编辑弹窗：初始居中，但在提示词输入框输入内容后弹窗自动下移的问题。要求弹窗打开后水平垂直居中且输入时不发生位移。

## 背景

`v-workbench-dialog` 指令在弹窗打开时把 `.el-dialog` 固定为 `position: fixed; margin: 0; top: Xpx`，但 Element UI 的 `el-dialog` 每次重渲染（输入触发 `v-model` 更新）都会通过 `:style` 重新写回默认 `margin-top: 15vh`，与固定定位叠加导致弹窗下移 15vh。实测输入前 top=115px、输入后 top=250px。

## 目标

- [x] 弹窗打开时水平垂直居中，不再依赖 Element UI 的 margin-top 默认定位
- [x] 输入提示词等内容触发重渲染时，弹窗位置保持不变
- [x] 移动、缩放、最大化、关闭重置等既有交互不受影响

## 验收标准

- 业务场景 Skill 新增/编辑弹窗打开居中，输入提示词前后弹窗 top 不变
- 弹窗移动/缩放/最大化/还原/关闭重开行为保持既有能力
- 前端测试、类型检查与构建通过

## 执行记录

- 2026-10-29 复现问题（输入前后 top 115px→250px），定位为 Element UI 重渲染重新写回 margin-top:15vh 与固定定位叠加。
- 2026-10-29 修复：指令打开时显式居中，CSS 用 margin-top:0 !important 锁定；新增居中回归测试。npm test 27/27、typecheck、build 通过，浏览器实测输入前后 top 均为 116.5px。

## 人工验收

- 打开业务场景 Skill 新增/编辑弹窗，确认初始居中；在调查提示词、决策包提示词输入内容，确认弹窗不再下移。
- 拖动标题栏移动、右下角缩放、最大化/还原、关闭重开，确认既有交互正常。
