## 需求

### ID&标题

业务处理新增 AI 预填

### 描述

业务处理第一步“开始模型分析”左侧新增「AI 预填」：弹窗输入一段业务描述，交模型解析出业务标题、业务说明，并按需匹配业务场景与数据库实例；解析结果只读预览，确认后回填表单。

## 背景

当前用户需要手工拆分标题/说明并自行选择场景与实例。模型已具备业务理解能力，可先解析自由文本，降低录入成本；预填不应创建任务，也不应改动已有数据。

## 目标

- [x] 新增不依赖任务的预填接口 `POST /api/v1/business-intake/draft`（TASK_READ，10–2000 字，60s 超时）
- [x] 新增模型能力与提示词模板，四个客户端实现全部落地；token 按当前用户记录
- [x] 场景/实例名称精确匹配，未命中或重名留空；输出按表单上限截断
- [x] 业务处理页新增弹窗、只读预览与“应用到表单”
- [x] 同步 OpenAPI 契约与前端类型/解析，补后端单测与前端构建验证

## 验收标准

- 点击「AI 预填」输入描述后可解析出标题/说明；场景与实例能按名称匹配。
- 预览只读；应用后非空字段覆盖表单，空字段保留原值。
- 模型失败提示可读错误，原表单不变；未匹配场景/实例不展示建议名称。
- 后端定向测试、契约校验、前端 typecheck/test/build 通过。
