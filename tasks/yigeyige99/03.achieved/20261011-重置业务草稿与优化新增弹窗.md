## 需求

### ID & 标题

自定义需求：重置业务草稿与优化新增弹窗

### 描述

完成一次业务处理后，再次点击“新建业务处理”仍显示上一次业务内容；业务场景 Skill 和大模型配置的新增弹窗未与当前工作台样式保持一致。

## 背景

业务处理向导被缓存以保留同一任务的操作状态，但导航入口未发出新建草稿信号，导致用户无法从同一入口开始新的处理。两个新增弹窗沿用 Element UI 默认外观，和工作台的暖白卡片、分组表单及操作区风格不一致。

## 目标

- [x] 每次从“新建业务处理”入口进入时清空上一份本地草稿并回到第一步。
- [x] 保持进行中的写请求安全，避免旧异步结果覆盖新的草稿状态。
- [x] 统一业务场景 Skill 与大模型配置新增/编辑弹窗的标题、表单和底部操作区样式。
- [x] 保持现有字段校验、密钥不回显、保存行为和权限规则不变。

## 验收标准

- 已创建任务后再次点击左侧“新建业务处理”，页面显示空白的业务标题和说明表单。
- 从任务列表点击新建业务处理也会开始新的草稿。
- 两个管理页弹窗具有一致的圆角暖白容器、清晰标题、表单间距和底部操作区，窄屏下仍可操作。
- 前端类型检查、生产构建、差异空白检查和相关 OpenSpec 严格校验通过。
