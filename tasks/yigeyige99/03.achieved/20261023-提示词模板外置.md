## 需求

### ID&标题

将 DeepSeekBusinessModelClient 的 instruction 提示词外置为可配置模板

### 描述

`DeepSeekBusinessModelClient` 中 5 个模型用例（选表、查询规划、业务处理初稿、调查方案、证据分析）的 instruction 提示词（角色定义、可访问 schema 白名单、SQL 生成规则、输出 JSON 格式）全部硬编码在 Java 代码里，应外置为可配置的提示词模板，代码只负责读取模板并拼接运行时 input。

## 背景

业务知识（表定位、字段语义、查询顺序）已外置到业务场景 Skill description。剩余的 instruction 属于「系统提示词 + 安全约束 + 输出契约」，仍硬编码在 `DeepSeekBusinessModelClient`。用户要求全部外置。安全已由 `EmsReadOnlySqlGuard` 代码兜底（schema 白名单 + 只读校验），因此 instruction 中的白名单是软提示，外置不影响安全。

## 目标

- [x] 新增 `governance.prompt_template` 表与初始模板数据（5 个模型用例）。
- [x] 新增提示词模板仓储与读取服务。
- [x] `DeepSeekBusinessModelClient` 不再硬编码 instruction，改从模板读取并拼接运行时 input。

## 验收标准

- `DeepSeekBusinessModelClient` 无硬编码 instruction 字符串。
- 模板内容与当前 instruction 等价，模型调用结果不变（复测 guidance 仍能正确查到审批配置）。
- 后端编译通过，复测通过。
