## 需求

### ID&标题

- EMS 财务系统业务域知识与工作台展示

### 描述

- 基于 `ems-财务系统-本地简易版` 的已核实结构信息，形成可复用的财务系统业务域知识。
- 不纳入 `claim`、`xxljob`、`arch_db`。
- 在左侧菜单增加“EMS业务知识域”，用于展示相应知识。

## 背景

- 本地简易版当前可用于核实库、表、字段、注释和部分外键，但关键业务表尚无可用样本数据。
- 后续业务场景分析需要先复用统一业务域和关键表知识，不能每次临时猜测数据对象。

## 目标

- [x] 将 EMS 业务域知识以受控只读接口提供给工作台。
- [x] 排除 `claim`、`xxljob`、`arch_db`，覆盖基础数据、流程、会计、预算、付款、稽核、智能审核、移动服务和运行配置域。
- [x] 在左侧菜单增加“EMS业务知识域”入口，并以既有工作台风格展示域、所属库、关键表和可信边界。
- [x] 补充后端与前端相关验证，并维护可复用的知识文档。

## 验收标准

- 已登录且具备既有工作台访问权限的用户可从左侧菜单进入“EMS业务知识域”。
- 页面展示不包含 `claim`、`xxljob`、`arch_db` 的业务域，且每个域包含用途、所属库、关键表及“结构已核实、业务关系待样本确认”的边界说明。
- 未授权访问遵循既有身份与路由保护机制；接口不返回真实人员、账号、单据、金额或连接信息。
- 后端单元测试、后端编译、前端类型检查和生产构建通过。
