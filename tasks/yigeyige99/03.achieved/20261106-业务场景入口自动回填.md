## 需求

### ID&标题

业务场景列表入口改名并自动回填业务场景

### 描述

- 业务场景列表行内操作按钮“开始处理”改为“业务处理”。
- 点击后跳转业务处理页，第一步的“业务场景”下拉框自动选中该场景，无需用户再手动选择。

## 背景

`BusinessSkillCatalog.startHandling` 已把 `skillId` 写入路由查询参数，创建任务时也会带上该标识，但业务处理页 `selectedSkillId` 未从路由初始化，导致界面下拉框仍为空、用户需要再选一次。

## 目标

- [x] 业务场景列表按钮文案改为“业务处理”
- [x] 业务处理页从路由 `skillId` 自动回填业务场景下拉框
- [x] 从左侧菜单直接进入业务处理时仍保持空白选择
- [x] 前端类型检查与生产构建通过

## 验收标准

- 业务场景列表点击“业务处理”后进入业务处理页，第一步“业务场景”已选中对应场景，创建任务请求携带该场景标识。
- 通过左侧菜单进入业务处理页时，业务场景保持未选择。
- `npm run typecheck` 与 `npm run build` 通过。

## 执行记录

- 2026-11-06：创建任务，调整 `BusinessSkillCatalog.vue` 与 `WorkbenchHome.vue`。
- 2026-11-06：按钮文案改“业务处理”；`WorkbenchHome` 新增 `applyRouteSceneSkill()`，在业务场景列表加载完成与 `resetDraft()` 时按路由 `skillId` 回填 `selectedSkillId`，菜单直接进入时无 `skillId` 则保持空白。
- 2026-11-06：收尾归档，创建提交 `feat: 20261106-业务场景入口自动回填`。
