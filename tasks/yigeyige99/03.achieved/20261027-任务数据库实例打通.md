## 需求

### ID&标题

任务数据库实例打通。

### 描述

1. 任务创建第一步可勾选数据库实例：未勾选则不需要数据库数据参与；勾选后模型分析打通对应实例。
2. 新增 OPERATOR 可读的启用数据库实例列表接口。

## 背景

- 当前模型分析默认使用第一个启用的数据库实例，无法按任务选择。
- 任务创建没有数据库实例入口，OPERATOR 也无法读取启用实例列表。

## 目标

- [x] 任务支持可选数据库实例并持久化，模型分析按所选实例执行；未选则不查数据库。
- [x] 新增 OPERATOR 可读的启用实例列表接口（不含连接配置/凭据）。
- [x] 前端第一步新增数据库实例选择并随创建任务提交。

## 验收标准

- [x] 创建任务时选择数据库实例后，任务持久化 `databaseConfigId`，模型分析使用该实例；不选则跳过 EMS 辅助查询。
- [x] `/api/v1/ems-database-configurations/enabled` 对 OPERATOR 可读，仅返回实例标识与名称。
- [x] 后端编译、相关测试、前端类型检查与构建通过。
