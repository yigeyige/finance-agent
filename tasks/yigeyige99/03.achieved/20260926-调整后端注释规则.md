## 需求

### ID&标题

调整后端注释规则

### 描述

将 Java Javadoc 置于注解之前；构造器、简单 getter/setter 和职责显而易见的简单方法无需添加方法注释。

## 背景

现有后端注释模板要求所有方法均注释，且部分 Javadoc 位于注解之后，不符合最新编码约定。

## 目标

- [x] 更新后端编码规范的注释要求。
- [x] 调整现有生产源码中注释与注解的位置关系，并移除无需保留的方法模板注释。
- [x] 完成差异检查和 Maven 测试。

## 验收标准

- Javadoc 位于其关联注解之前。
- 构造器、简单访问器和职责显而易见的简单方法不保留强制模板注释。
- `mvn test` 通过。
