## 需求

### ID&标题

主按钮统一改为淡主题橙

### 描述

各页面中 Element 默认蓝色主按钮（`type="primary"`）统一改为主题橙，但用淡橙底 + 深褐文字，避免高饱和色块过于显眼；文字型操作按钮一并由蓝转橙。

## 背景

工作台强调色已统一为 `#f9b334`，但 Element UI 2.0.0 未做主题定制，`el-button--primary` 仍是官方蓝 `#409EFF`，与暖色侧栏、卡片和步骤条冲突。

## 目标

- [x] 实心主按钮改为淡橙底 `#f9c96b` + 深褐字 `#4a3200`，悬停加深为 `#f9b334`
- [x] 描边主按钮（`is-plain`）改为浅橙底 + 深橙字
- [x] 禁用态使用低对比浅橙，保持“不可点”观感
- [x] 文字型操作按钮由蓝转橙
- [x] 默认标签与分页当前页高亮由蓝转橙，语义色标签保持不变
- [x] 前端生产构建通过

## 验收标准

- 各页面 `type="primary"` 按钮为淡橙配色，无蓝色残留；悬停、禁用态颜色正确。
- 表格内文字操作按钮为深橙，删除类按钮仍保持红色（`.skill-delete-action` 使用 `!important` 不受影响）。
- `npm run build` 通过。
