## 需求

### ID & 标题

自定义需求：优化侧栏高度与移除管理页总览

### 描述

侧边栏不得随右侧页面内容高度缩短；移除任务列表、业务场景 Skill 和大模型配置页面占据空间且不提供必要信息的总览栏。

## 背景

当前侧边栏仅按工作台内容高度渲染，右侧内容较短时未覆盖完整视口。三个管理入口均有重复页面标题和数量的总览卡片，降低有效内容密度。

## 目标

- [x] 侧边栏保持完整视口高度，并在菜单超出视口时独立滚动。
- [x] 移除任务列表、业务场景 Skill 与大模型配置页面的总览卡片及无用代码样式。
- [x] 保持筛选、分页、表格、管理操作和权限菜单行为不变。
- [x] 同步前端样式规范、完成静态检查和前端构建验证。

## 验收标准

- 右侧页面内容少于或多于一屏时，左侧栏均覆盖浏览器视口高度且菜单可访问。
- 三个管理入口标题后直接进入操作区与内容区，不再显示总览/概览栏。
- 任务列表仍默认 10 条/页，查询、重置、新建和双击只读详情入口可用。
- 前端类型检查、生产构建与差异空白检查通过。
