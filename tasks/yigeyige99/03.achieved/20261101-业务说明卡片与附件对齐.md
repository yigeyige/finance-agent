## 需求

### ID&标题

业务说明卡片与附件标签对齐优化

### 描述

业务说明页签的“附件材料（可选）”标签与选择按钮一同靠右；宽屏左侧业务信息卡片和右侧聊天框等高，且左侧卡片不出现纵向滚动条，说明输入框保持适中高度。

## 背景

当前仅附件按钮靠右，标签仍在左侧。上轮取消业务说明的视口约束后左侧卡片恢复自然高度，与聊天框之间出现底部空白。

## 目标

- [x] 附件标签、选择按钮和说明文字靠右。
- [x] 宽屏业务说明左侧卡片与聊天框等高，操作区靠下。
- [x] 业务说明卡片无独立纵向滚动条，模型协作保留左侧内部滚动。

## 验收标准

- 桌面宽屏下两张卡片下缘对齐，业务说明输入框保持适中高度，左侧无内部纵向滚动条。
- 附件标签、按钮和提示文字靠右；模型协作的左侧滚动不受影响。
- 窄屏自然排列，附件列表增长时内容不被裁切。
- 前端测试、类型检查、构建和 OpenSpec 校验通过；用户手动验收运行界面。
