## 需求

### ID&标题

20261010 增加账号密码登录与管理员初始化

### 描述

增加登录页和账号密码登录逻辑；页面右上角点击当前用户后展示下拉菜单并提供退出登录。默认初始化 `admin` 管理员账号，默认密码按用户指定值生成不可逆散列，并提供对应数据库迁移与初始化插入脚本。

## 背景

当前系统仅通过 local/test 请求头或外部 Principal 解析身份，不具备业务人员可直接使用的账号密码登录入口，也没有密码凭据表和默认管理员初始化数据。内网部署需要一个简单、安全且可退出的会话登录闭环。

## 目标

- [x] 提供用户名密码登录、退出登录、会话身份解析及未登录失败关闭。
- [x] 增加登录页、受保护路由跳转、右上角用户下拉菜单和退出入口。
- [x] 新增默认 `admin` 平台管理员、密码凭据表及不可逆散列初始化数据。
- [x] 保持现有角色权限矩阵和业务接口授权边界不变。

## 验收标准

- 正确账号密码登录后返回当前身份并可访问管理员全部菜单；错误凭据只返回通用失败信息。
- 会话 Cookie 为 HttpOnly，退出后 Cookie 和服务端会话均失效；未登录访问受保护接口和路由会被拒绝或跳转登录页。
- 数据库迁移幂等写入默认管理员、PLATFORM_ADMIN 角色和密码散列，不包含明文密码。
- 密码验证使用 PBKDF2-HMAC-SHA256 和常量时间比较，不记录密码、散列、盐或会话令牌。
- 后端测试、前端类型检查与生产构建通过。
