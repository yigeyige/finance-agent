# 自定义需求：每个表补充创建人与更新时间审计字段

## 需求

### ID&标题

- 自定义需求：每个表补充创建人与更新时间审计字段

### 描述

- V1–V7 已建立的每张业务表均需具备 `created_by`、`created_at`、`updated_by`、`updated_at` 四个审计字段。
- 已执行基线不得直接改写，使用新增前向迁移补齐字段，并同步领域模型方案与主规格。

## 背景

当前 Flyway 基线已在本地开发库执行，但各表的创建人/更新人字段不完整。审计字段需覆盖现有七个业务 schema 的全部表，并兼容系统生成记录和既有数据。

## 目标

- [x] 为 V1–V7 的每张业务表增加 `created_by`、`created_at`、`updated_by`、`updated_at`。
- [x] 通过 V8 前向迁移实现，不修改已安装的 V1–V7 文件。
- [x] 更新领域模型方案、迁移说明、OpenSpec 主规格和静态校验。
- [x] 在本地开发库执行 V8 并核对全部表字段。

## 验收标准

- 七个 schema 下的每张业务表均存在四个审计字段。
- `created_at`、`updated_at` 使用 `timestamptz`，新增记录有时间默认值。
- `created_by`、`updated_by` 使用 UUID，并在提供值时关联 `iam.agent_user`。
- V1–V7 文件内容不被改写，V8 可重复由 Flyway history 控制。
- 静态迁移校验、后端编译/测试通过；本地数据库字段核对通过。
