## 需求

### ID&标题

数据探索表列表统一展示表名并在左侧目录内滚动

### 描述

数据探索页面左侧表列表统一以表名展示；点击 schema 展开大量表时，纵向滚动限制在左侧表列表区，不撑高整个页面。

## 背景

目录树当前优先把表注释作为节点主标题，注释为空时才显示表名。目录树没有独立高度与滚动容器，展开长列表会撑高页面。

## 目标

- [x] 左侧目录树表节点统一显示表名，保留按表名或注释搜索。
- [x] 选表后的元数据仍使用真实表注释，不受节点标题调整影响。
- [x] 宽屏长目录只在左侧表列表区滚动，窄屏保持内容可访问。

## 验收标准

- 有注释与无注释的表均以表名为唯一节点文本；选表仍能查看正确字段。
- 搜索注释仍可找到表；选中表的内部注释值不被表名替换。
- 展开大量表时页面不因左侧树持续变高，滚动条在左侧列表区域；窄屏仍能访问全部表。
- 前端测试、类型检查、构建及 OpenSpec 严格校验通过；页面由操作人手动验收。
