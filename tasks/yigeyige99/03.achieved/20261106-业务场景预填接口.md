## 需求

### ID&标题

业务场景 AI 预填接口（后端）

### 描述

为业务场景表单提供 AI 预填：用户输入业务描述、可选数据库实例，按目标（调查提示词 / 决策包提示词 / 流程文件提示词）分别生成内容；调查提示词同时生成场景名称。表名先按文本中的 schema 与日志/临时/备份等规则筛选，剩余表名全部传给模型。

## 背景

业务场景维护者需要手写多段提示词，且难以结合真实表结构。现有 `business-intake-prefill` 只服务业务处理第一步，不能直接复用；本接口独立新增，不改动既有 intake 与任务编排链路。

## 目标

- [x] 新增 `POST /api/v1/business-scene-skills/prefill`（新建 PLATFORM_USER、编辑仅场景维护者）
- [x] 按 target 生成调查/决策包/流程文件提示词；决策包依赖调查提示词、流程文件依赖决策包提示词，缺失时阻断
- [x] 表名筛选：schema 初筛 + 日志/临时/备份/日期后缀/MQ/事务类排除，剩余全部传入；无表时仍生成并提示
- [x] 新模型方法与提示词模板（V58），独立 60s 超时；token 按当前用户记录
- [x] 契约与单测通过

## 验收标准

- 非维护者编辑预填返回 403；未登录 401；文本长度非法 400。
- 决策包/流程文件缺少前置提示词时返回 400 与中文提示，不调用模型。
- 调查提示词返回名称与内容；另两个 target 只返回内容。
- 筛选统计（使用/排除表数）随响应返回；筛选后为空时 warning 提示且生成成功。
- 后端编译、定向测试、契约校验通过。
