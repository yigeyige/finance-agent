## 需求

### ID&标题

自定义需求，ID 为空。业务场景 Skill 附件。

### 描述

业务场景 Skill 可上传并持久化附件（json/xml/xlsx 等），模型调查分析时按需调用相应附件，避免一股脑全传浪费 token。

## 背景

现有附件为任务级、临时、一次性（创建任务初稿用，不落库）。本需求是场景级、可复用的知识附件：多个任务使用同一场景时共用；调查阶段按两段式模型自选使用附件正文。

## 目标

- [x] 新增业务场景附件表，支持上传、列表、删除
- [x] 前端场景编辑弹窗支持上传附件与填写摘要
- [x] 调查阶段两段式按需使用场景附件正文，不一股脑全传

## 验收标准

- [x] 每场景最多 5 个附件、单文件不超过 100KB，附件摘要必填
- [x] 模型第一轮只接收附件清单（文件名+摘要），按需请求正文；一次最多注入 2 个附件完整正文
- [x] 相关测试、前后端编译与 OpenSpec 严格校验通过
