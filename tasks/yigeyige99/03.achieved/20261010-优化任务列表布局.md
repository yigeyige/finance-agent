## 需求

### ID&标题

20261010 优化任务列表卡片布局与查询操作区

### 描述

参照用户提供的仪表盘截图，优化任务列表的布局样式块。查询字段应位于表格外部，查询、重置和新建业务处理按钮应位于同一操作区。

## 背景

当前任务列表将筛选表单和数据表格置于同一容器，操作层级不清晰。需要沿用现有 Element UI 组件与视觉体系，以概览卡片、筛选操作区和数据表格的分层方式提高业务人员的使用效率。

## 目标

- [x] 将任务列表调整为概览、筛选操作和业务处理记录三个清晰区块。
- [x] 将业务标题、处理状态筛选字段移至表格容器外部。
- [x] 将查询、重置、新建业务处理按钮置于同一操作区。
- [x] 保持现有筛选、分页、双击只读详情和权限相关接口行为不变。

## 验收标准

- 页面在桌面端呈现圆角卡片、分隔列和柔和强调色的区块层级，且不增加冗余副标题。
- 查询字段不再处于表格面板内，三个操作按钮在同一操作区可见。
- 标题关键字、处理状态筛选、分页和双击打开详情继续可用。
- 前端 TypeScript 校验和构建通过。
