## 需求

### ID&标题

自定义需求，ID 为空。决策包生成纳入逐轮修订的调查结论与证据。

### 描述

生成决策包时保留现有任务原始信息、场景决策包提示词和跨轮累计数据库证据，同时读取最新已保存的调查草稿，将逐轮修订得到的调查结论及草稿证据送入模型，并把本次使用的草稿快照固定到决策包。避免用户多轮修订未影响最终决策包。

## 背景

当前调查模型每轮成功后保存最新草稿，并另行累积数据库证据；但决策包生成服务只读取任务信息、累计数据库证据与场景提示词，没有读取草稿。此任务是流程文件产物生成任务的前置小切片，不扩展流程结构、文件生成或页面交互。

## 目标

- [x] 决策包生成服务读取并校验最新已保存调查草稿；不存在时给出明确中文提示
- [x] 模型输入保留现有任务信息、提示词和累计证据，并加入最新调查草稿全文（含结论和草稿证据）
- [x] 决策包修订固化本次使用的草稿快照；后续调查修订不改变旧包，内容变化仍按现有摘要规则生成新修订
- [x] 增加聚焦测试并完成后端编译、相关测试与 OpenSpec 严格校验

## 验收标准

- [x] 相同任务信息和累计数据库证据下，调查结论修订后再次生成决策包，模型收到新草稿且保存的新修订包含该草稿快照
- [x] 草稿中的证据随草稿进入模型；累计数据库证据仍按现有去重和数量上限处理，不重复扩增顶层证据
- [x] 没有已保存草稿时不调用决策包模型，返回明确中文提示；旧决策包及历史修订不变
- [x] 不新增数据库迁移、前端交互、独立事实稿、权限流程或文件转换逻辑
