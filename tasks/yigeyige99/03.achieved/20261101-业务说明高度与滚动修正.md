## 需求

### ID&标题

业务处理创建页业务说明高度与滚动修正

### 描述

用户反馈业务说明输入框被拉得过高，左侧卡片出现滚动条。将输入框调整为适中高度，业务说明步骤左侧不出现独立滚动条；模型协作仍保留左侧内部滚动。

## 背景

上一轮让业务说明表单吸收可用视口高度，使输入框随视口拉伸，超出卡片后出现滚动条。用户截图显示此布局过高。

## 目标

- [x] 业务说明输入框高度适中且不再随视口拉伸。
- [x] 业务说明步骤左侧卡片不出现独立纵向滚动条。
- [x] 模型协作步骤左侧独立滚动和两个操作按钮居右保持可用。

## 验收标准

- 截图尺寸的桌面视口下，业务说明输入框明显低于原来的填满高度，左侧卡片无内部滚动条。
- 模型协作结果较长时仍由左侧卡片内部滚动；选择附件、开始模型分析仍靠右。
- 前端测试、类型检查和构建通过；运行界面由用户手动验收。
