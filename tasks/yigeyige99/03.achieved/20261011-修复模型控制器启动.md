## 需求

### ID&标题

修复业务模型控制器本地启动失败

### 描述

本地启动本次 Excel 附件分析版本时，Spring 无法选择 `BusinessModelController` 的构造器，导致应用上下文启动失败；修复后重新启动并验证健康端点。

## 背景

附件分析功能为控制器增加了可注入测试替身的第二个构造器，但没有指定 Spring 的注入构造器。应用 JAR 在创建控制器 Bean 时因此报“无默认构造器”。

## 目标

- [x] 明确业务模型控制器的 Spring 注入构造器，保持测试替身构造器可用。
- [x] 补充启动上下文回归测试，防止同类 Bean 装配失败。
- [x] 重新构建并启动独立本地实例，验证健康与就绪端点。

## 验收标准

- 本地 profile 下可启动包含 Excel 附件改动的 JAR，且 `/actuator/health`、`/actuator/health/readiness` 返回成功。
- 现有控制器的模型初稿、方案与证据分析接口映射保持不变。
- 相关测试、后端编译与 OpenSpec 严格校验通过；本地人工页面验收由用户执行。
