# 新建业务处理界面：业务说明隐藏聊天框、协作提示入聊天框、按钮格式统一

## 需求

### ID&标题

新建业务处理界面：业务说明隐藏聊天框、协作提示入聊天框、按钮格式统一

### 描述

业务处理工作台（三步向导）存在三处界面问题，需按用户确认的方向微调：

1. 业务说明页签仍展示右侧模型聊天框，但此时尚未进入协作，应隐藏聊天框、让表单区占满整行。
2. “可继续在聊天框发送修改意见补充证据”提示目前以页面 alert 展示，应改到聊天框输入框内作为占位提示文字。
3. 模型协作页签“保存任务”按钮与“生成决策包”按钮格式不一致，应统一为小号。

## 背景

业务处理工作台 `WorkbenchHome.vue` 分“业务说明—模型协作—决策包”三步。当前第一步（业务说明）右侧聊天框仍占位渲染（仅禁用交互），与“尚未开始协作”的状态不符；第二步（模型协作）的补充证据提示放在页面 alert，与聊天上下文割裂；同页“保存任务”按钮为 `size="small"`，而“生成决策包”按钮为默认尺寸，视觉不一致。

经与用户确认：第一步隐藏聊天框且表单区占满整行；提示改为聊天框输入框 placeholder；“保存任务”与“生成决策包”统一为小号。

## 目标

- [x] 业务说明页签隐藏右侧模型聊天框，业务表单区占满整行
- [x] “可继续在聊天框发送修改意见补充证据”改为聊天框输入框 placeholder 提示
- [x] “保存任务”与“生成决策包”按钮统一为小号（`size="small"`）

## 验收标准

- [x] `activeStep === 0` 时不渲染模型聊天框，业务表单列宽为 24 列并占满整行
- [x] `guidance.needMoreEvidence` 为真时，聊天框输入框 placeholder 显示补充证据提示；移除原页面 alert
- [x] “保存任务”与“生成决策包”按钮均使用 `size="small"`
- [x] 前端类型检查与构建通过
