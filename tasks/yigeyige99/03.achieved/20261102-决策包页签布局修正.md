# 任务创建界面：决策包页签修订标签位置与滚动布局

## 需求

### ID&标题

任务创建界面：决策包页签修订标签位置与滚动布局

### 描述

业务处理工作台决策包页签（第三步）存在三处布局问题：

1. “修订 {{ revision }}”标签位于“返回模型协作”按钮左侧，应移到“业务决策包”标题右侧并上下居中。
2. 左侧表单区存在「外壳卡片 → 业务决策包卡片 → 子卡片」三层嵌套，业务决策包卡片应扁平化（保留外壳卡片，去掉“业务决策包”独立边框/背景）。
3. 决策包页签未纳入视口内滚动，纵向滚动条不在左侧表单区，整页滚动导致右侧聊天框不可见。

## 背景

决策包页签（`activeStep === 2`）的 `--viewport` 视口滚动机制当前仅对 `activeStep < 2` 生效，导致第三步整页滚动、右侧聊天框随内容滚走；同时第三步 DOM 为「外壳卡片 → `section.packet-result-panel`（业务决策包）→ 子卡片」三层卡片嵌套。修订标签当前放在 `collaboration-actions` 里，位于“返回模型协作”按钮左侧。

经与用户确认：保留外壳卡片，扁平化“业务决策包”层（去掉其独立边框/背景），子卡片直接平铺在外壳内。

## 目标

- [x] “修订”标签展示在“业务决策包”标题右侧且上下居中
- [x] “业务决策包”层扁平化，去掉独立边框/背景，子卡片直接平铺在外壳卡片内
- [x] 决策包页签左侧内容在左侧表单区内部纵向滚动，滚动条在左侧表单区，右侧聊天框保持可见

## 验收标准

- [x] “修订”标签位于“业务决策包”标题右侧、垂直居中，不再位于“返回模型协作”按钮左侧
- [x] “业务决策包”不再有独立边框/背景/padding，数据对象/操作/结论/证据卡片与流程文件卡片直接平铺在外壳卡片内
- [x] 决策包页签左侧卡片内部纵向滚动，右侧聊天框在向下滚动时保持可见
- [x] 前端类型检查与构建通过
