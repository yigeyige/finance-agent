# 加固诊断与配置

## 需求

### ID&标题

加固诊断与配置

### 描述

根据后端编码规范审查结果，修复诊断接口暴露、探针异常静默处理、生产配置校验、数据库探针超时配置和 AgentScope API 探针接入边界问题。

## 背景

当前系统尚未实现统一 IAM，不应以临时认证机制替代后续认证契约；因此诊断 API 默认关闭，待 IAM 能力交付后再按权限重新启用。

## 目标

- [x] 默认关闭自定义诊断 API，并隐藏公开 health 的内部组件名称。
- [x] 为探针失败补充严格脱敏的结构化追溯信息。
- [x] 使用允许列表和约束校验保护生产配置与诊断超时配置。
- [x] 将 AgentScope 编译兼容性探针移出生产源码。
- [x] 补充相关自动化测试并通过 Maven 验证。

## 验收标准

- 默认配置下，请求 `/api/v1/diagnostics` 返回 404。
- 公开 health 不返回 database、modelStub、sourceStub 等内部组件名称。
- 缺失、非法或不安全的生产配置会在启动校验阶段失败，且不输出秘密值。
- 数据库诊断超时来自绑定配置，不通过字符串拼接修改 JDBC URL。
- 所有后端 Maven 测试通过，且无需启动本地环境或连接外部系统。
