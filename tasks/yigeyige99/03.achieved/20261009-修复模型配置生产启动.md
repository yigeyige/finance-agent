## 需求

### ID&标题

- 修复模型配置与生产启动校验一致性

### 描述

- 真实模型连接已改由数据库中的大模型配置维护，生产启动校验不得再要求旧的 DeepSeek API Key、地址和模型名称环境变量。
- 生产仍必须校验部署级模型密钥加密主密钥；未启用模型连接时应用可以启动，真实模型调用必须安全失败并提示管理员先启用配置。

## 背景

- 当前 `ProductionStartupValidator` 与其单元测试仍依赖旧的 `finance-agent.deep-seek.*` 运行时连接配置，和大模型配置页面、数据库运行时读取方式冲突。

## 目标

- [x] 删除生产启动对旧模型连接环境变量的依赖。
- [x] 保留并强化部署级加密主密钥的生产校验。
- [x] 补齐生产启动和无启用模型配置时的测试。

## 验收标准

- 生产配置只提供数据库、身份、存储、来源、字段策略和模型加密主密钥时可通过启动校验。
- 未启用数据库模型配置时，真实模型调用返回安全、可理解的失败信息且不产生伪结果。
- 旧模型连接环境变量不再作为生产启动门槛。

## 执行记录

- 2026-10-09：根据系统设计审查发现的生产启动与模型配置冲突创建任务。
- 2026-10-09：生产启动不再要求旧 DeepSeek 连接变量，改为校验部署级模型加密主密钥；未启用连接维持调用期安全失败。已通过生产启动与模型配置服务测试、后端编译和 change 级 OpenSpec 严格校验。
