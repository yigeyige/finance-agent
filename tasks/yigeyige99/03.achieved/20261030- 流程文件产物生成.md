## 需求

### ID&标题

自定义需求，ID 为空。流程文件产物生成。

### 描述

依据用户填写的初版流程信息或附件，先通过多轮调查形成可修订的流程调查结论和关联证据；用户点击生成决策包时固定本次调查结论及证据，再由用户点击生成文件。模型按文件提示词产出中间表示，Java 转换为 EMS 流程模型和适用的配置文件；提供单文件及可选配置 ZIP 下载，由用户在 EMS 导入和补全。

## 背景

「审批流程生成-隆地」场景沿用现有多轮调查反馈，不另建事实稿；调查结论本身承载结构化流程事实。决策包保存当次调查结论和证据，文件只读取决策包固定内容及文件提示词。模型不直接手写约 35KB 的编辑器 JSON，由 Java 转换器按五类节点、顺序流转和排他分支生成。EMS 现有 ZIP 入口允许只含模型或模型加部分配置，但导入即部署并设置运行版本，用户已接受并自行补全。首版只支持本场景；会签/并行等仅标记遗漏原因。文件批次仅保留最新与上一次。

## 目标

- [x] 本场景的多轮调查结论展示结构化流程事实、证据与待补项；生成决策包时固定当次结论和证据，文件只取该决策包的推荐方案及固定内容
- [x] 场景 Skill 新增生成文件提示词；V30 修订本场景调查、决策包提示词，通用模板仅在实际阻断时最小调整
- [x] 模型产出中间表示；Java 按已核对 EMS 导入契约转换五类节点、顺序/排他流转，流程模型必生成，其他三种配置只在适用时生成
- [x] 文件按来源决策包修订留存最新及上一次批次；生成失败不改变旧批次，缺口标记及最低导入状态可见
- [x] 前端提供单文件下载和可选配置的导入 ZIP，模型文件固定包含，并提示 EMS 导入自动部署/设置运行版本
- [x] 单次模型输入不超过 1M 及实际模型上限，超限提示缩减材料，不自动分块

## 验收标准

- [x] 决策包固定当次调查结论与证据；后续调查修订不改变旧包，文件生成不重新读取变化中的调查草稿
- [x] 未生成含调查结论的决策包不可生成文件；文件只按推荐方案及本场景提示词生成，超范围形态和未知项明确标记
- [x] ZIP 必含 EMS 编辑器 JSON 模型文件，三种配置按适用性和用户选择纳入；静态契约满足最低导入要求，否则标为待修复，不宣称可导入
- [x] 新决策包不自动重生文件；成功生成后仅保留最新与上一次，失败保留旧批次，旧文件标明来源修订
- [x] 静态转换测试、前后端编译及 OpenSpec 严格校验通过；EMS 导入与运行效果由用户手工验证
