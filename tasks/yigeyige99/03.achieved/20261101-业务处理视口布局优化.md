## 需求

### ID&标题

业务处理创建页视口布局与操作对齐优化

### 描述

业务说明步骤减少底部留白、增大业务说明输入框，将选择附件和开始模型分析按钮置于右侧；模型协作步骤让左侧内容独立纵向滚动，避免整页滚动后看不到聊天框。

## 背景

当前聊天面板按视口填高，左侧表单自然高度造成留白；模型协作左侧内容较长时撑高整页。

## 目标

- [x] 业务说明输入框使用可用空间，减少左侧底部留白。
- [x] 选择附件和开始模型分析按钮居右。
- [x] 桌面端模型协作左侧独立滚动，聊天框保持在视口内。

## 验收标准

- 桌面宽屏下业务说明输入区变高，底部无明显空白，两个操作按钮靠右。
- 模型协作左侧内容超出时只在左侧内容区纵向滚动，聊天框始终可见。
- 窄屏仍按单列自然滚动，不裁切操作内容。
- 静态检查、前端测试、类型检查与构建通过；本地运行由用户手动验证。
