## 需求

### ID&标题

审批流程候选表与超时兜底

### 描述

审批流程调查时，schema 搜索未召回 `act_re_model`/`act_re_procdef`，模型只能查空的 `psc_act_re_model`；同时提示词扩写后超过领域 2000 字符限制，返回 400 MODEL_CONTEXT_INVALID；模型网关偶发 504。

## 背景

- 选表依赖 `snapshot.search(title + description, 20)`，场景提示词中的表关系没有进入搜索文本。
- `BusinessSceneSkill` 对 `investigationPrompt` 的校验上限仍是 2000。
- V40 提示词需要标题兜底和前置表为空时停止下游查询。
- 网关 504 需要一次重试。

## 目标

- [x] 审批流程场景 schema 搜索加入核心表提示
- [x] 调查提示词上限从 2000 提升到 8000
- [x] V40 增加标题兜底和前置表为空停止下游规则
- [x] 模型网关 504 重试一次
- [x] 验证 guidance 不再 400，并能召回 `act_re_model`

## 验收标准

- [x] 审批流程场景候选表包含 `act_re_model` 等核心表
- [x] `investigationPrompt` 长提示词不再触发 MODEL_CONTEXT_INVALID
- [x] 前置流程为空时不再查询节点/流转
- [x] 504 可重试一次
- [x] 实际 guidance 返回 200
