- [x] 在 `contracts/openapi`、`contracts/json-schema`、`contracts/examples` 保存版本化源契约。

- 所有 schema 有 `$id`/版本。
- `additionalProperties` 默认关闭。
- 有效/无效样例结果符合预期。
- 负向检查：额外字段、错误枚举、无格式时间和越界数组样例失败。
- 实现方检查：`scripts/verify-contracts.*`。
- 人工验证：无。
- 完成证据：契约文件清单和校验输出。
