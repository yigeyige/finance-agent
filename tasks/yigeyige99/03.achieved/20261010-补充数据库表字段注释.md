## 需求

- 为 finance-agent 数据库的全部业务表和字段补充中文注释，并将可执行 SQL 脚本放入后端数据库迁移目录。

## 背景

- 当前七个业务 schema 的 34 张业务表、427 个字段均未配置数据库注释，影响数据治理、排障与后续维护。

## 目标

- [x] 根据实际数据库元数据列出业务表和字段范围。
- [x] 新增前向 Flyway SQL，为全部现行业务表和字段写入中文注释。
- [x] 提供静态完整性校验，确保脚本覆盖实际业务字段且不修改历史迁移。

## 验收标准

- 迁移脚本位于 `backend/src/main/resources/db/migration/`，版本号高于当前 V14。
- 脚本覆盖 `iam`、`task`、`evidence`、`packet`、`harness`、`knowledge`、`governance` 的全部业务表和字段。
- 脚本不包含连接凭据、不执行数据读写，且保留既有 Flyway 历史文件不变。

## 执行记录

- 2026-10-10：通过只读数据库元数据查询确认当前业务表与字段范围。
- 2026-10-10：新增 `V15__add_schema_comments.sql`，覆盖 33 张业务表、427 个字段实例及 201 个唯一字段名；对未登记表、字段失败关闭。未执行数据库迁移。
- 2026-10-10：迁移静态校验、后端资源编译和变更级 OpenSpec 严格校验均通过。
