## 需求

### ID&标题

决策包页签新增流程产物下载弹窗

### 描述

从任务列表打开任务详情后，在“决策包”页签增加“流程产物”按钮，点击弹窗展示最近流程文件批次，支持重新下载单个文件或 ZIP。

## 背景

任务详情页 `TaskDetail.vue` 的决策包步骤只展示决策包内容，没有流程产物卡片；流程产物卡片只在业务处理向导第三步存在。用户从任务列表进入后无法查看或重新下载已生成的 BPMN 文件。

## 目标

- [x] 决策包页签增加“流程产物”按钮
- [x] 弹窗展示最近批次、决策包修订、导入状态、待补信息和文件列表
- [x] 支持重新下载单个文件和 ZIP
- [x] 空状态和失败提示清晰

## 验收标准

- [x] 任务详情决策包页签可见“流程产物”按钮
- [x] 弹窗能加载并展示最近批次文件
- [x] 单个文件、ZIP 下载可用
- [x] 无产物时显示空状态
- [x] 前端 typecheck/build 通过
