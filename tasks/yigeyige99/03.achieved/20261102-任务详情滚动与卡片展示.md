## 需求

### ID&标题

任务详情模型协作与决策包滚动和卡片展示优化

### 描述

任务详情的模型协作和决策包页签内容较长时，只在表单内容区纵向滚动，顶部步骤栏保持可见。模型协作的检查结论和关联证据分别按决策包样式显示为卡片；检查结论平铺整行，并按分号或句号分行。

## 背景

当前任务详情的模型协作与决策包内容自然撑高整页，滚动后步骤栏离开视线。模型协作结论与证据共用一个面板，结论未按句拆分。

## 目标

- [x] 模型协作与决策包在宽屏长内容下由卡片内容区独立纵向滚动，步骤栏保持可见。
- [x] 检查结论和关联证据分别以现有决策包卡片样式展示。
- [x] 检查结论文字占满卡片内容宽度，按分号或句号分行。

## 验收标准

- 内容较多时，两个页签的表单内容区出现纵向滚动条，页面步骤栏仍可见；窄屏不裁切内容。
- 检查结论与关联证据各有卡片边界；无数据时在对应卡片显示原有中文空状态。
- 检查结论含中文/英文分号或中文句号时按句分行，原文内容不丢失。
- 前端测试、类型检查、构建和 OpenSpec 严格校验通过；本地运行由用户手动验收。
