## 需求

### 描述

- 将业务场景 Skill、大模型配置、任务列表与只读详情、推荐方案修订及任务创建的场景 Skill 关联补入 `contracts/`。

- `contracts/README.md` 规定契约目录是前后端唯一契约源，但近期新增接口尚未同步，存在前后端演进漂移风险。

## 目标

- [x] 在 OpenAPI 中定义新增路径、请求与响应模型、权限失败语义。
- [x] 对齐前端临时生成类型与服务层，移除重复的 API DTO 声明。
- [x] 补充契约样例、运行契约校验及相关构建验证。

## 验收标准

- OpenAPI 覆盖所有已实现的新接口和扩展字段。
- 前端页面与 service 复用 `frontend/src/api/generated` 中的契约类型。
- 契约校验、前端类型检查与生产构建通过。
