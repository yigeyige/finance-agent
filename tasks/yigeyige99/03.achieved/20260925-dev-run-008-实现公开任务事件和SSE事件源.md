## 背景

本任务来自财务共享智能运维 Agent 开发任务基线中的 `DEV-RUN-008`，用于实现公开任务事件和 SSE 事件源。

## 目标

- [x] 定义业务事件类型、序号、重放游标和权限。
- [x] SSE 只输出状态、审批需求、工具进度、公开理由和结果引用。
- [x] REST 提供断线后的状态/事件查询。
- [x] 交付并核对以下产物：事件仓储/发布器、SSE endpoint、事件 JSON Schema。

## 验收标准

- 事件单调排序、可按游标恢复。
- VIEWER 只能看到发布后允许事件。
- 不输出推理链、prompt、源原文或凭证。
- 负向检查：跨任务订阅、旧 token、恶意 Last-Event-ID 和敏感内容注入被拒绝/过滤。
- 实现方检查：事件 schema 和权限契约检查。
- 人工验证：用户断开/重连 SSE 并检查重放。
- 完成证据：事件样例、过滤结果和用户验证。
