# 合成 Worker 写入证据

## 需求

### 标题

合成 Worker 写入证据并接续纵向切片

### 描述

在已审批的合成步骤后，受控执行固定合成场景，写入可复核的证据记录，使核心合成纵向切片可以继续完成后续决策包、复核、发布、交接和关闭验证。

## 背景

当前纵向切片已完成范围确认、步骤提案与步骤审批，但没有可触发的合成 Worker 写入事实快照、覆盖记录和发现，因此按脚本设计在证据检查点停止。功能仅服务 local 合成验证，不读取真实业务数据，也不扩大到真实来源或生产执行。

## 目标

- [x] 提供受审批、范围和测试身份约束的合成步骤执行入口。
- [x] 写入最小且可追溯的合成证据、覆盖度、发现和计算见证。
- [x] 使核心合成纵向切片越过证据检查点，并验证后续既有流程。

## 验收标准

- 仅已获批的合成步骤可执行，且不接收任意场景、来源或真实业务数据。
- 证据写入包含任务、步骤、范围和运行版本关联，并保留审计链。
- 重复执行具有明确幂等或拒绝语义，不产生不可解释的重复证据。
- 相关单元/接口契约测试、Maven 编译和 OpenSpec 严格校验通过。
