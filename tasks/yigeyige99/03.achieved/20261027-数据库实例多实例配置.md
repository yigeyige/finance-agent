## 需求

### ID&标题

数据库实例多实例配置与数据探索切换。

### 描述

1. 侧边菜单「EMS数据库配置」改名为「数据库实例」。
2. 去掉数据库实例的唯一启用约束，允许配置并同时启用多个数据库实例。
3. 数据探索页增加「实例」下拉切换，默认选择第一个启用的实例。
4. 业务处理模型分析按任务选择数据库实例并持久化——本次仅记录需求，不做实现，后续再调整。

## 背景

- 当前 `governance.ems_database_connection_config` 表有部分唯一索引，强制同时只能一个 `enabled=true`；`enable()` 会先 `disableAll`。
- 数据探索与模型分析都通过 `requireEnabled()` 取唯一启用实例，无法配置多个实例并切换。
- 用户希望先放开多实例配置，数据探索可切换实例；模型分析的实例选择留待后续任务。

## 目标

- [x] 侧边菜单与数据库配置页标题改为「数据库实例」。
- [x] 去掉数据库唯一启用约束，允许多个实例同时启用。
- [x] 数据探索页新增实例下拉切换，默认第一个启用实例，目录/字段/查询按所选实例执行。
- [x] 模型分析仍使用第一个启用实例，不破坏现有业务处理流程。

## 验收标准

- [x] 侧边菜单显示「数据库实例」，进入后页面标题一致。
- [x] 数据库实例列表可同时启用多个实例，启用一个不影响其他已启用实例。
- [x] 数据探索页可通过下拉切换实例，目录、字段结构和查询结果对应所选实例。
- [x] 未选择实例时默认使用第一个启用实例，与原有行为一致。
- [x] 后端编译、相关测试、前端类型检查与构建通过。
