## 需求

### ID&标题

- 完善大模型配置启停生命周期

### 描述

- 管理员除创建、编辑、启用大模型连接外，还需要能明确停用当前连接。
- 停用后系统不得继续选择该连接；模型调用应复用既有“未启用模型”的安全失败语义，且页面能够清晰展示并执行停用操作。

## 背景

- 主规格已要求平台管理员可停用连接，但现有后端和页面只实现了唯一启用，无法主动进入“无启用模型”的安全维护状态。

## 目标

- [x] 新增受管理员保护的模型连接停用接口，并保留审计字段。
- [x] 明确停用后的运行时行为与契约，且不暴露 API Key。
- [x] 在模型配置页面提供确认式停用操作并完成服务测试与前端构建验证。

## 验收标准

- 平台管理员可停用当前启用模型，列表立即显示未启用；停用非启用配置不产生错误状态。
- 停用后 `requireEnabled` 不返回已停用连接，真实调用维持已有安全失败提示。
- OpenAPI、前端生成边界、服务调用与页面操作保持一致；相关测试和构建通过。

## 执行记录

- 2026-10-09：根据系统设计审查发现的启停生命周期缺口创建任务。
- 2026-10-09：新增管理员停用接口与确认式页面操作；停用保留配置和密钥密文、更新审计字段，重复停用保持幂等。
- 2026-10-09：`ModelConnectionConfigServiceTest`、后端编译、契约校验、前端类型检查和生产构建均通过；生产构建保留现有单包体积告警。
