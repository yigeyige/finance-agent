## 需求

### ID&标题

决策包流程产物入口按任务业务场景的流程文件提示词显示

### 描述

任务详情的决策包页签中，如果任务对应业务场景的流程文件提示词为空，则隐藏“流程产物”按钮。可异步判断，不影响决策包主体展示。

## 背景

当前按钮仅依据决策包存在与否显示，而流程产物生成服务在场景提示词为空时拒绝生成。

## 目标

- [x] 按任务关联的业务场景 ID 和当前有效提示词控制入口。
- [x] 异步读取入口状态，决策包主体不等待该查询。
- [x] 维持任务权限边界，不对前端传输提示词正文。

## 验收标准

- 提示词为 null、空串或纯空白时按钮不显示；有有效提示词且有决策包时显示。
- 无决策包或业务场景无效时按钮不显示。
- 任务详情仍先完成主体展示；无权任务不能借入口状态查询获取场景配置。
- 后端相关测试、前端测试与编译检查、OpenSpec 校验通过；运行时由操作人手动验证。
