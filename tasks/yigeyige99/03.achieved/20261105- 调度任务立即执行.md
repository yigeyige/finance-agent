## 需求

### ID&标题

调度任务增加立即执行一次按钮

### 描述

在调度任务页执行时间的“保存”按钮右侧增加“立即执行一次”按钮，点击后触发当前业务数据清理任务一次，并可查看最新运行日志。

## 背景

当前清理任务只能等待定时触发；已有清理逻辑、管理员权限和运行日志可复用。本次不修改保留期限、清理范围或定时计划。

## 目标

- [x] 平台管理员可从调度任务页手动触发一次业务数据清理。
- [x] 防止重复触发，并在页面显示提交、运行及失败反馈和最新日志。
- [x] 完成相关后端和前端自动化验证。

## 验收标准

- “立即执行一次”紧邻“保存”右侧，二次确认后触发固定清理任务；不保存尚未提交的时间草稿。
- 手动执行与定时执行共用清理逻辑和日志；不改变下一次定时计划。
- 非管理员被拒绝；重复提交受控，运行结束后可在右侧查看最新日志。
- 仅做静态检查与编译测试，本地启动和手动页面验收由用户执行。
