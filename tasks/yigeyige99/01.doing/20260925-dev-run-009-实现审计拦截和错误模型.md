## 目标

- [ ] 统一领域错误、HTTP 状态和 `retryClass`。
- [ ] 对任务、范围、审批、工具、确认、复核、发布、交接和管理动作写审计。
- [ ] 错误中不泄漏 SQL、路径或秘密。
- [ ] 交付并核对以下产物：错误目录、异常映射、审计拦截器。

## 验收标准

- 可重试/新审批/人工对账明确。
- 审计能重建关键业务动作。
- 负向检查：审计写失败时关键动作失败关闭。
- 负向检查：错误正文不含敏感信息。
- 实现方检查：错误/OpenAPI 契约检查。
- 人工验证：用户抽查失败响应和审计。
- 完成证据：错误目录和正反样例。
