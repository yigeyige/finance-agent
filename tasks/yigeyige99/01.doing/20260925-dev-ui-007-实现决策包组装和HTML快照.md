## 验收标准

- JSON 为权威。
- HTML 与摘要对应。
- 缺必备依据时 validator 阻止进入复核。
- 负向检查：模型生成的自由文本不能覆盖事实字段。
- 负向检查：实际业务影响不得凭配置推断。
- 实现方检查：Packet JSON Schema、快照摘要契约和构建。
- 人工验证：用户审阅 HTML 与结构化内容。
- 完成证据：草稿样例和校验结果。
