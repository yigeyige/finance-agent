## 需求

### ID&标题

基于全部有效证据分析并生成业务决策包

### 描述

用户点击生成业务决策包时，服务端必须基于该任务此前全部有效证据先完成独立模型分析，再生成“生成即完成”的 `businesspacket`。决策包不接入其他 packet 的复核、发布或交接状态机，但必须可追溯、不可变、并发安全并受 OPERATOR 权限保护。

## 背景

- 当前实现只是用最新业务草稿加按 schema/table/purpose 去重后的证据直接装配，没有执行“基于历轮证据再分析”。
- 去重保留最新会掩盖时间变化与冲突，不符合“全部证据参与分析”的业务意图。
- 全部证据参与是指所有有效证据进入权威索引和分块分析链路，不等于把全部原始数据放入单次提示词。
- 用户已确认以独立的、生成即完成的 `businesspacket` 为准；无有效证据时不得生成正式包。
- 本切片依赖前两个切片；本轮只完成任务与 OpenSpec 提案，不实施。

## 目标

- [ ] 生成前分析全部有效证据，保留冲突、时序和缺口
- [ ] 固化证据 ID、摘要 digest、Skill 修订、模板版本、分块分析及模型元数据
- [ ] 生成不可变且立即完成的 businesspacket 修订，保证幂等和并发安全
- [ ] 限定 OPERATOR 生成和查看决策包及累积证据，VIEWER 不得访问

## 验收标准

- [ ] 无有效证据时拒绝正式决策包并保留“待核查业务分析草稿”语义
- [ ] 相同内容不新增修订，变化时新增不可变修订，旧版可追溯
- [ ] 并发生成不会出现重复 revision 或 `max+1` 竞争
- [ ] `openspec validate analyze-evidence-businesspacket --strict` 通过
