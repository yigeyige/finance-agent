# 实现发布查看、交接和关闭

## 背景

本任务来自财务共享智能运维 Agent 开发任务基线中的 `DEV-UI-010`，用于实现发布查看、交接和关闭。

## 前置条件

- 依赖：[DEV-UI-009](20260925-dev-ui-009-实现发布前重查和原子发布.md)。
- 来源基线：[06-P0工作台与决策包.md](../solutions/开发任务基线/06-P0工作台与决策包.md)

## 目标

- [ ] OPERATOR/VIEWER 使用同一发布视图。
- [ ] 显示核查时点、版本、覆盖和限制。
- [ ] OPERATOR 登记外部整改责任/流程引用/状态并关闭调查。
- [ ] 不把调查关闭等同整改完成。
- [ ] 交付并核对以下产物：发布查看、交接 API/页面和权限守卫。

## 验收标准

- VIEWER 只能看获授权发布修订。
- 交接后历史仍可查。
- 关闭不修改发布内容。
- 负向检查：VIEWER 查看草稿、交接修改 revision、无责任引用关闭失败。
- 实现方检查：权限/状态契约和构建。
- 人工验证：用户以 OPERATOR/VIEWER 完成查看和交接。
- 完成证据：双角色结果和交接记录。
