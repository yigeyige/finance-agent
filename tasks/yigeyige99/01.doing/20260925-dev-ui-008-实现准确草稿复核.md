## 目标

- [ ] 复核绑定 draft ID、content digest、scope revision、runtime bundle。
- [ ] 页面明确显示被复核摘要。
- [ ] 内容任何改变生成新草稿并使 review 失效。
- [ ] 交付并核对以下产物：复核 API、页面、状态守卫和审计。

## 验收标准

- 首期同一 OPERATOR 可复核，但发起/复核动作分开记录。
- 预留双人策略。
- 负向检查：摘要不符、旧 scope、旧 runtime bundle 和未完成专业确认禁止批准。
- 实现方检查：复核契约。
- 人工验证：用户复核后修改内容并验证失效。
- 完成证据：review/draft 对照。
