## 需求

### ID&标题

自定义需求，ID 为空。流程文件产物生成。

### 描述

决策包（文字方案）确认后，管理员可触发生成可导入 EMS 的审批流程配置文件（部门审批流 / 节点参数配置 / 审批规则 / BPMN 定义，2~4 个）：模型产出流程中间表示（结构化小 JSON），Java 构件转换器精确生成文件内容并落库，前端提供下载。

## 背景

「审批流程生成-隆地」场景的最终产物是 4 个可导入 EMS 的配置文件。经 grill 共识确定方案：模型不直接手写大 JSON（BPMN 编辑器 JSON 35KB、结构复杂、错误率高），而是产出业务语义的中间表示（节点/流转/分档/模板），由 Java 的 5 类构件工厂（draft/approve/accountant/task-pool/import-erp）+ 通用图组装 + 分层布局精确转换。文件生成是独立步骤：必须已有决策包才可触发；重复生成覆盖式更新；中间表示留档可回溯。

## 验收标准

- [ ] 有决策包的任务可触发生成，产出文件结构精确匹配 EMS 导入格式（对照样例校验字段）
- [ ] 未生成决策包的任务无法触发生成；重复生成覆盖旧产物
- [ ] 中间表示校验失败或转换失败时明确报错，不落半截产物
- [ ] 相关测试、前后端编译与 OpenSpec 严格校验通过
