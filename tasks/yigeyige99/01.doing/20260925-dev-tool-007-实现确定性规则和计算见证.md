## 目标

- [ ] 规则核心使用版本化 Java。
- [ ] 输入由获准快照规范化。
- [ ] 输出 finding、输入/输出摘要、算法/规则版本和快照 ID。
- [ ] 实现独立 `rules.recompute`。
- [ ] 交付并核对以下产物：规则 SPI、首个人员引用规则、witness 服务、复算工具。

## 验收标准

- 相同证据/版本复算为 MATCHED。
- 规则改变产生新 witness，不覆盖旧结果。
- 负向检查：缺快照、字段越权、摘要不匹配和未知规则版本不能确认为确定性结论。
- 实现方检查：黄金向量契约检查。
- 人工验证：用户执行数据库快照复算。
- 完成证据：输入/输出摘要和复算记录。
