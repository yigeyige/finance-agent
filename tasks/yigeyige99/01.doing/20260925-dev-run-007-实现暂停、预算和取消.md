## 目标

- [ ] 实现模型不可用、源不可用、预算耗尽、可恢复失败和取消。
- [ ] 模型暂停不阻断已存证据查看和确定性功能。
- [ ] 取消释放租约但不删除历史。
- [ ] 交付并核对以下产物：暂停策略、预算计数器、取消服务、错误码。

## 验收标准

- 状态和可执行动作明确。
- 等待/暂停不占 Worker。
- 任务不自动关闭。
- 负向检查：预算耗尽后继续调用模型、取消后继续领取步骤均失败。
- 实现方检查：状态/预算契约检查。
- 人工验证：用户模拟模型不可用和预算耗尽。
- 完成证据：暂停恢复记录、预算事件。
