## DEV-UI-007 实现决策包组装和 HTML 快照

- **状态**：`TODO`
- **依赖**：`DEV-DATA-005`、`DEV-UI-006`。
- **实施**：从结构化对象组装问题/前提、范围、来源、当前/未来/未知、计算、专业判断、建议、待业务确认、验证准备和交接占位；生成 canonical JSON、digest 和 HTML；不实现 PDF。
- **产物**：Packet assembler、validator、模板和草稿 API/页面。
- **验收**：JSON 为权威；HTML 与摘要对应；缺必备依据时 validator 阻止进入复核。
- **负向检查**：模型生成的自由文本不能覆盖事实字段；实际业务影响不得凭配置推断。
- **实现方检查**：Packet JSON Schema、快照摘要契约和构建。
- **人工验证**：用户审阅 HTML 与结构化内容。
- **完成证据**：草稿样例和校验结果。

## DEV-UI-008 实现准确草稿复核

- **状态**：`TODO`
- **依赖**：`DEV-UI-007`。
- **实施**：复核绑定 draft ID、content digest、scope revision、runtime bundle；页面明确显示被复核摘要；内容任何改变生成新草稿并使 review 失效。
- **产物**：复核 API、页面、状态守卫和审计。
- **验收**：首期同一 OPERATOR 可复核，但发起/复核动作分开记录；预留双人策略。
- **负向检查**：摘要不符、旧 scope、旧 runtime bundle 和未完成专业确认禁止批准。
- **实现方检查**：复核契约。
- **人工验证**：用户复核后修改内容并验证失效。
- **完成证据**：review/draft 对照。

## DEV-UI-009 实现发布前重查和原子发布

- **状态**：`TODO`
- **依赖**：`DEV-TOOL-008`、`DEV-UI-008`、`DEV-DATA-007`。
- **实施**：发布命令触发全范围重查；无影响变化后在同一事务写不可变 revision、audit、outbox 和任务状态；幂等返回原修订。
- **产物**：发布服务、API、状态页面和事务实现。
- **验收**：发布前新增引用使草稿 stale；审计失败整体回滚；已发布修订不可变。
- **负向检查**：重复发布、并发发布、旧 review、审计失败和生效时间跨越。
- **实现方检查**：发布 API/事务契约；故障注入由用户执行。
- **人工验证**：用户执行变化/回滚/重放场景。
- **完成证据**：revision、audit、事务和用户结果。

## DEV-UI-010 实现发布查看、交接和关闭

- **状态**：`TODO`
- **依赖**：`DEV-UI-009`。
- **实施**：OPERATOR/VIEWER 使用同一发布视图；显示核查时点、版本、覆盖和限制；OPERATOR 登记外部整改责任/流程引用/状态并关闭调查；不把调查关闭等同整改完成。

- **负向检查**：VIEWER 查看草稿、交接修改 revision、无责任引用关闭失败。
- **实现方检查**：权限/状态契约和构建。
- **人工验证**：用户以 OPERATOR/VIEWER 完成查看和交接。
- **完成证据**：双角色结果和交接记录。
