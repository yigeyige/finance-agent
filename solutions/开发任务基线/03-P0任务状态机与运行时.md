# P0 任务状态机与运行时任务

> 上级索引：[开发任务总览](00-财务共享智能运维Agent-开发任务总览.md)
> 目标：让人工发起的有界任务在中断、重试和等待人工时保持可控、可恢复和可审计。

## DEV-RUN-001 实现权威任务状态机

- **状态**：`TODO`
- **依赖**：`DEV-DATA-003`、`DEV-DATA-009`。
- **实施**：编码附件 A 的状态、事件、守卫和转移；状态改变只允许通过应用服务；持久化前使用 `row_version`；记录每次状态事件。
- **产物**：状态机、转移表、守卫、状态事件仓储。
- **验收**：正常路径、暂停、恢复、取消和 stale 路径完整；非法转移无数据库副作用。
- **负向检查**：Harness、Controller 或仓储调用不能绕过状态机直接推进业务状态。
- **实现方检查**：状态转移表参数化契约检查、编译。
- **人工验证**：用户抽查状态事件。
- **完成证据**：状态覆盖矩阵和检查结果。

## DEV-RUN-002 实现任务发起、前提和范围确认

- **状态**：`TODO`
- **依赖**：`DEV-RUN-001`、`DEV-DATA-002`。
- **实施**：实现任务草稿、运维提供前提、范围草拟/确认和不可变 scope revision；三类字段权限分别保存；范围改变使相关审批和草稿 stale。

- **实现方检查**：API/JSON Schema 契约检查。
- **人工验证**：用户手工发起、确认和修改范围。
- **完成证据**：请求响应样例、状态和审计记录。

## DEV-RUN-003 实现步骤提议和审批卡

- **状态**：`TODO`
- **依赖**：`DEV-RUN-002`。
- **实施**：保存一个推荐和最多两个备选；审批绑定目标摘要、来源、范围、字段策略、查询模板和调用上限；生成不可变 approval revision 和短期内部 permit。
- **产物**：步骤/审批应用服务、API、守卫和契约。
- **验收**：相同绑定且次数内可重试；任一绑定改变都需新审批；能力令牌不返回模型或浏览器。
- **负向检查**：过期、撤销、旧范围、调用次数耗尽、字段扩大和模板漂移均拒绝。
- **实现方检查**：审批绑定测试向量和契约检查。
- **人工验证**：用户验证审批卡内容和重试行为。
- **完成证据**：正反请求样例、审批摘要。

## DEV-RUN-004 实现 PostgreSQL Worker 和租约

- **状态**：`TODO`
- **依赖**：`DEV-RUN-001`、`DEV-DATA-009`。
- **实施**：使用 `FOR UPDATE SKIP LOCKED` 领取就绪步骤；建立租约、心跳、过期接管和优雅停止；API/Worker 使用隔离线程池/连接池；等待人工任务不持有租约。
- **产物**：Worker、调度器、租约服务、配置项。
- **验收**：一个任务最多一个活动租约；停止领取后运行步骤在安全点结束；等待任务不消耗 Worker。
- **负向检查**：双 Worker、心跳丢失、过期接管和时钟偏差场景有确定行为。
- **实现方检查**：编译和租约 SQL 契约；并发运行由用户测试。
- **人工验证**：用户执行双实例/双 Worker 测试（可在同一 JAR 内配置多个 Worker）。
- **完成证据**：租约记录、接管结果、线程/池配置。

## DEV-RUN-005 实现幂等和调用意图

- **状态**：`TODO`
- **依赖**：`DEV-RUN-003`、`DEV-RUN-004`。
- **实施**：幂等键使用 `taskId + stepId + approvalRevision + invocationNo`；工具调用前写意图，完成后写摘要和结果状态；区分明确失败和结果未知。
- **产物**：幂等服务、调用状态机、重复请求处理。
- **验收**：成功调用重放持久化结果；未知状态不盲重试；相同发布命令返回同一修订。
- **负向检查**：重复 HTTP、Worker 重启和网络超时不产生重复副作用。
- **实现方检查**：幂等契约检查。
- **人工验证**：用户重复提交同一请求并检查结果。
- **完成证据**：幂等用例和数据库记录。

## DEV-RUN-006 实现业务 checkpoint 与恢复判定

- **状态**：`TODO`
- **依赖**：`DEV-RUN-003`、`DEV-RUN-005`、`DEV-DATA-006`。
- **实施**：在审批后、调用意图后、裁剪结果后、确定性计算后、草稿后和发布复核后创建检查点；恢复时重验当前步骤、审批、范围、版本、租约和幂等状态。
- **产物**：checkpoint 服务、恢复决策器、恢复 API/Worker 路径。
- **验收**：返回 `RESUME`、`REPLAY_RESULT`、`NEW_APPROVAL_REQUIRED` 或 `MANUAL_RECONCILIATION`；不得跳过人审。
- **负向检查**：旧 approval、旧 runtime bundle、旧 scope 和未知调用状态不能自动恢复。
- **实现方检查**：恢复决策表契约检查。
- **人工验证**：用户在多个安全点终止进程并恢复。
- **完成证据**：恢复矩阵和用户故障注入结果。

## DEV-RUN-007 实现暂停、预算和取消

- **状态**：`TODO`
- **依赖**：`DEV-RUN-001`、`DEV-RUN-004`。
- **实施**：实现模型不可用、源不可用、预算耗尽、可恢复失败和取消；模型暂停不阻断已存证据查看和确定性功能；取消释放租约但不删除历史。
- **产物**：暂停策略、预算计数器、取消服务、错误码。
- **验收**：状态和可执行动作明确；等待/暂停不占 Worker；任务不自动关闭。
- **负向检查**：预算耗尽后继续调用模型、取消后继续领取步骤均失败。
- **实现方检查**：状态/预算契约检查。
- **人工验证**：用户模拟模型不可用和预算耗尽。
- **完成证据**：暂停恢复记录、预算事件。

## DEV-RUN-008 实现公开任务事件和 SSE 事件源

- **状态**：`TODO`
- **依赖**：`DEV-RUN-001`、`DEV-RUN-003`。
- **实施**：定义业务事件类型、序号、重放游标和权限；SSE 只输出状态、审批需求、工具进度、公开理由和结果引用；REST 提供断线后的状态/事件查询。
- **产物**：事件仓储/发布器、SSE endpoint、事件 JSON Schema。
- **验收**：事件单调排序、可按游标恢复；VIEWER 只能看到发布后允许事件；不输出推理链、prompt、源原文或凭证。
- **负向检查**：跨任务订阅、旧 token、恶意 Last-Event-ID 和敏感内容注入被拒绝/过滤。
- **实现方检查**：事件 schema 和权限契约检查。
- **人工验证**：用户断开/重连 SSE 并检查重放。
- **完成证据**：事件样例、过滤结果和用户验证。

## DEV-RUN-009 实现审计拦截和错误模型

- **状态**：`TODO`
- **依赖**：`DEV-DATA-007`、`DEV-RUN-001`。
- **实施**：统一领域错误、HTTP 状态和 `retryClass`；对任务、范围、审批、工具、确认、复核、发布、交接和管理动作写审计；错误中不泄漏 SQL、路径或秘密。
- **产物**：错误目录、异常映射、审计拦截器。
- **验收**：可重试/新审批/人工对账明确；审计能重建关键业务动作。
- **负向检查**：审计写失败时关键动作失败关闭；错误正文不含敏感信息。
- **实现方检查**：错误/OpenAPI 契约检查。
- **人工验证**：用户抽查失败响应和审计。
- **完成证据**：错误目录和正反样例。
