## 3. P0 合成纵向切片

### 3.1 合成场景

建立一套不含真实人员和真实业务数据的合成财务配置源：

- 合成人员 `EMP-SYN-001` 被运维人员声明为“已离职”的任务前提；
- 当前存在两个流程/角色配置引用；
- 存在一个未来计划生效引用；
- 一条关系路径可完整枚举，一条路径模拟分页失败；
- API 和数据库视图对一个字段返回冲突；
- 返回体含一个允许读取但禁止留存字段，并可注入一个禁止读取字段；
- 调查完成后、发布前新增一个范围内引用。

### 3.2 必走流程

1. OPERATOR 通过统一认证发起任务并记录前提来源。
2. 确认系统、对象、路径、时间和字段范围。
3. Harness 提议一个推荐步骤和最多两个备选。
4. OPERATOR 逐步批准；系统冻结六项绑定。
5. 只读适配器查询、裁剪、分页并保存最小快照和覆盖记录。
6. 确定性程序区分当前/未来/未知，生成 computation witness 并复算。
7. 运维逐项确认不可计算的专业解释。
8. 生成包含事实、未知、建议方案、“待业务确认”和验证准备的草稿。
9. 运维复核准确草稿摘要。
10. 发布前重查发现新增引用，旧复核失效；刷新草稿并重新复核。
11. 新复核后原子发布不可变修订和审计。
12. VIEWER 查看同一修订；OPERATOR 登记外部流程引用并关闭调查。
13. 在查询、分析、模型生成和发布前分别注入进程中断，验证恢复。

### 3.3 P0 出口证据

- API/工具/模型 schema 校验报告；
- SourceCatalog 合成版本和三类字段权限矩阵；
- 全流程状态事件、租约、幂等和 checkpoint 记录；
- 快照、coverage、finding、witness、review、revision、audit 的数据库证据；
- 禁止字段全库、日志、trace、workspace、prompt 元数据和导出搜索结果；
- 源写权限失败记录；
- 发布事务回滚和重放证据；
- Harness 各能力验证记录；
- 同一版本组合的 SBOM、编译和测试报告。

## 5. 详细验收矩阵

### 5.1 任务和审批

| 用例 | 期望 |
|---|---|
| 未确认范围运行步骤 | 拒绝，保持 `WAITING_SCOPE_CONFIRMATION` |
| 同时批准两个当前步骤 | 后者冲突，始终只有一个 current step |
| 相同参数且次数内重试 | 可沿用批准，增加 `used_calls` |
| 改变来源/范围/字段/模板/次数 | 旧批准失效，需新审批 |
| 审批过期或撤销后恢复 | 转 `WAITING_STEP_APPROVAL` |
| 用户补充信息但不改变范围 | 记录前提/会话修订，不自动重新批准 |
| 自然语言要求扩大范围 | 生成范围变更建议，不能直接执行 |

### 5.2 数据边界

| 用例 | 期望 |
|---|---|
| 只返回批准留存字段 | 正常快照 |
| 返回允许读但禁止留存字段 | 内存裁剪，持久化/送模/日志均无该值 |
| 返回禁止读取字段 | 整次调用失败关闭，所有持久化介质无该值 |
| 模型请求未批准字段 | 工具网关拒绝 |
| 查询模板尝试写 SQL | 构建/运行契约拒绝；只读账号写操作失败 |
| 测试数据混入真实资金字段 | 数据分类检查失败，测试中止 |

### 5.3 事实、规则和覆盖

| 用例 | 期望 |
|---|---|
| 当前有效条件完整 | `CURRENT_EFFECTIVE` |
| 未来起效时间明确 | `FUTURE_SCHEDULED`，不计入当前数量 |
| 时间或规则缺失 | `UNDETERMINED` |
| API/视图事实冲突 | `UNKNOWN_SOURCE_CONFLICT`，模型不可裁决 |
| 同证据/规则复算 | 输出摘要匹配并记录 `MATCHED` |
| 规则版本变化 | 新结果使用新 witness，旧结果不覆盖 |
| 缺页/关系路径失败 | coverage `PARTIAL`，禁止全范围否定 |
| 分页期间总量变化 | 重试或标记不完整 |
| RAG 与源快照冲突 | 源快照作为当前事实，文档仅作背景并提示差异 |

### 5.4 草稿、复核和发布

| 用例 | 期望 |
|---|---|
| 专业判断未逐项确认 | 草稿显示待确认，不能冒充确定性结论 |
| 复核后草稿内容改变 | review 摘要失配，禁止发布 |
| 复核后新增/删除/变化 | 草稿 stale，刷新并重新复核 |
| 源版本不变但生效时间跨越 | 重新分类，受影响草稿 stale |
| 审计插入失败 | 修订、任务状态、outbox 全部回滚 |
| 同幂等键重复发布 | 返回同一修订，不重复发布 |
| 尝试更新已发布修订 | 数据库/应用拒绝 |
| VIEWER 访问未发布草稿 | 403/404；只能看已发布同一视图 |

### 5.5 恢复和并发

| 用例 | 期望 |
|---|---|
| 实例在查询前终止 | 重启后验证批准并继续 |
| 查询超时且结果不明 | 不盲重试，转人工对账 |
| 快照提交后终止 | 重放快照，不重复查源 |
| 两个 Worker 领取同任务 | 唯一活动租约保证只有一个成功 |
| 租约过期接管 | 新 Worker 获得租约并基于 checkpoint 恢复 |
| 等待人工 30 天 | 不占 Worker，不自动关闭；旧审批按策略失效 |
| 模型不可用 | 模型步骤暂停；确定性查询/查看仍可用 |
| 预算耗尽 | 停止模型步骤并转人工，不继续消费 |

### 5.6 Harness

执行[附件 C 的功能、安全和故障注入清单](附件C-Harness能力映射与验证.md#12-验证清单)。每项须保留版本、输入、结果和证据，不能只记录“框架支持”。

## 6. 黄金数据和准确率

### 6.1 黄金数据组成

至少覆盖：人员/岗位/角色引用、流程节点配置、组织或权限范围、当前与未来生效、来源冲突、缺失关系路径、无匹配但覆盖完整、无匹配且覆盖不完整。所有样本使用批准字段，并保存预期 finding、coverage 和 packet 结构。

### 6.2 指标定义

P1 先量测再设阈值：

- 配置事实精确率/召回率（以人工签署黄金事实为基准）；
- 当前/未来/未知分类准确率；
- 全范围否定结论的违规次数；
- 专业判断误标为确定性结论的次数；
- 禁止字段暴露和源写入次数；
- 人工每任务审批/复核次数及耗时；
- 任务端到端时延、源调用次数、模型 token 和成本；
- 中断恢复成功率和重复副作用次数。

三项硬门禁始终为零容忍：禁止字段持久化或送模、源系统写入、未经准确复核的发布。

## 7. 性能和容量量测

不预设生产并发数字。P1 用三档样本（典型、大范围、边界）量测：

- API P50/P95；
- 单步骤源查询、裁剪、持久化和规则计算时间；
- 单任务快照/证据/JSONB/HTML 大小；
- 活动 Worker、数据库连接和模型并发；
- 等待任务数量对运行任务的影响；
- 精确知识扫描与 HNSW 候选的规模拐点。

据此确定 `TBC-CAP-*`、池大小、任务预算、索引和是否需要多实例/消息中间件。首期架构不提前引入这些复杂度。

## 8. 安全与供应链验收

- JDK、AgentScope BOM、Spring Boot、Vue、数据库驱动和 pgvector 版本有锁定清单。
- 构建生成 SBOM，依赖扫描结果有处置；例外包含风险、补偿控制、负责人和截止时间。
- 测试与生产使用同一签名制品，不在生产直接编辑代码、规则、提示或 schema。
- 密钥只通过受控环境变量注入，日志和诊断包无明文。
- 数据库迁移角色独立，应用角色无 DDL；源凭证无写权限。
- 工具、技能、规则、提示、源映射和 runtime bundle 均版本化、测试、发布、审计。
- Vue 2.7.16 停止维护风险已有例外记录和后续迁移议题。

## 9. 签署矩阵

| 对象 | 必须签署角色 | 可由同一自然人兼任 | 记录要求 |
|---|---|---|---|
| 规则集 | 技术实施人 + 功能运维 | 可以 | 两个角色、时间、版本分别记录 |
| 数据源/字段 | 系统或数据负责人 + 功能运维 | 可以 | 来源、字段、权限、版本分别记录 |
| 版本发布 | 技术角色 + 功能角色 | 可以 | 制品摘要、迁移、runtime bundle、门禁结果 |
| 技能发布 | 平台管理员 | 可以 | 内容摘要、工具权限、测试证据 |
| 知识发布 | 资料责任人/管理员 | 可以 | 来源、版本、适用范围、抽样结果 |

当前一个管理员可以完成复核，但系统仍保存分角色、分动作记录，为后续双人策略保留能力。
